# 调试日志文字修正（第 1 遍复查）

exe 中“設定錯誤 … act[%d] qq[%d] dir[%d]”一类格式串共四条（tmp 扫描 swd32.exe）：

| 地址 | 原文 |
|---|---|
| 0x0049F66C | 設定錯誤 GUID[%d]\nact[%d] qq[%d] dir[%d] |
| 0x0049F6B0 | 設定錯誤\nGUID%d ,act[%d] qq[%d] dir[%d] |
| 0x0049FD0C | 設定錯誤 \nact[%d] qq[%d] dir[%d] |
| 0x004A03F0 | 頭定符號設定錯誤 \nact[%d] qq[%d] dir[%d] |

重建有 16 处把 0x0049F66C 的换行写成空格（「設定錯誤 GUID[%d] act[%d]…」，含 talk_event.cpp 的 LogActError），4 处把 0x0049FD0C／0x004A03F0 的换行写成空格（「設定錯誤  act[%d]…」）。exe 中没有空格版本。已全部改回 \n。

受影响的已验证函数（各自重新记 diff 与 exact）：0x00405430、0x00405500、0x00408E70、0x0040E0B0、0x0040F280、0x0040F6D0、0x004120B0、0x004147E0、0x004149B0、0x00414B60、0x00414CE0。
- 差异（diff 轮）：上述调试日志文字与 exe 不符。已改正。复核一致（exact 轮）。

## 第二次扫描：日志文字与 exe 字符串比对

脚本 tmp/log_text_scan.py 把源码中每条 DebugLog／ErrorLog 的字面量（还原转义）转成 Big5，在 exe 的字符串中查找，找不到时再按空格拆成“标题 + 正文”分别查找。已验证函数中不符的：
- 0x00405500 RolePath::RunScript：「路徑系統 無效的指令」缺「\nGUID(%d)-(%d)」（0x0049F740 + 0x0049F74C）；「變數不合法(%d)(%d)」「數值不合法(%d)(%d)」缺末尾 \n（0x0049F7C4、0x0049F820）。
- 0x00406580：「路徑沒有設定 >> GUID(%d)」缺「\n ACT (%d)\nQQ (%d)\nPATH (%d)」（0x0049F8D8）。
- 0x0040B7F0：「!! 警告 !! %s」应为「!! 警告 !!\n號碼字串太長\n%s」（0x0049FDC8），「錯誤的號碼字串 %s」应为「錯誤的號碼字串\n%s」（0x0049FDA4）。
- 0x00411530：标题与正文写成两个参数（只输出了标题），应为「更新角色串列 找不到角色(%d)/[%d] 」（0x004A028C + 0x004A029C）。
- 差异（diff 轮）：上述文字已改正。复核一致（exact 轮）。

其余不符的都在尚未验证的 0x00427920（事件命令）中，随该函数核对时改正。
