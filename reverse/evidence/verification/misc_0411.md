# 0x00411490..0x00412050：角色行表、名字框、计数、场景效果、方向与暂停横幅

## 0x00411490 Field::InsertRole

行号 = (i32)y / 16 + 20（0x50 / 4）；空行直接放入；只有一个节点时，节点 y ≤ 新角色 y（无符号）且节点 id ≥ 新 id（16 位无符号）则接在其后，否则放到行首；多个节点时先比行首（y ≤ 且新 id ≥ 行首 id 则放到行首），再逐个找“当前 y ≤ 新 y、当前 id ≥ 新 id、下一个 id ≤ 新 id”的位置，找不到接到行尾。重建一致；行号越界时不写（越界，不复现）。exact。

## 0x00411530 Field::RemoveRole

从 `row` 行起逐行（到地图高度 0x4B7934 为止）找 id，单节点与多节点的摘除方式、`keep == 1` 时返回、否则按 flags & 3 层重新插入，与重建一致。
- 差异（diff 轮）：找到地图高度仍没有该角色（循环结束时行号等于高度；起始行号大于高度时不记）时，原版调 nullsub_1(0x4A028C「更新角色串列」, 0x4A029C「找不到角色(%d)/[%d] 」, id, layer)，重建缺这条调试日志。已补 DebugLog（同样的条件与参数）。修正后复核一致（exact 轮）。

## 0x00411620 Field::ResetRows

三层行表各 (高度 + 40) 项，全部为空。一致。exact。

## 0x00411700 Game::DrawTextInput

0x00480AD0 只是 `mov eax, [ecx+0Ch]`，返回值未用；名字框 0x2449 画在 (x − 0x6C, y − 0x2E)；文字复制最多 0x40 字节到共用缓冲区 0x4FBAC8（各使用者都先写入或清零再读，重建用局部变量），单字节的高位字节显示为 '@'；颜色 (0x15, 0xF, 8)，大字体样式 4；光标框 (x + 11 × 光标, y, 11, 0x16, 0x14, 0xD, 0, 5)。一致。exact。

## 0x004117F0 ActDrawer::DrawCounter

数字 0x2354 从右往左，每位 x += −2 − 宽，画在 y + 1；最后标签 0x245E 画在 (x − 0x28, y − 8)；模式 0x14，透明度取全局 dword_4C9A24（Game::counterAlpha）。重建经参数传入，四个调用点（店铺、存档画面、地图、菜单）传的都是 counterAlpha，绘制期间不变。exact。

## 0x00411D00 Scene::ResetEffects

调 0x0040F500..0x0040F670 七个释放函数（FreeEffects、FreeSpritesA、FreeSpritesB、FreeNodes、FreeAnimations、FreeMarks、ResetLeaves）；渐变步长 0x4A9A00、0x4A94B8、0x4C97F0 清零；shake（0x4ACE70，0x80 字节）填 0xCF；heatCounts（0x4AB2F8）填 1；heatLengths（0x4AB8FC）填 4；heatFrame（0x4CAE90）清零；0x4AC9BC 清 0x100 字节（越过 0x30 个双字的 heatOffsets，deviations.md 第 211 行登记，只清该数组）。exact。

## 0x00411D90 Game::DiskFreeMegabytes

原版：GetDiskFreeSpaceExA(NULL) 的调用者可用字节，(High << 12) + (Low >> 20)，即字节数右移 20 位后截成 32 位；载入 KERNEL32 或取函数失败返回 0xFFFFFFFF。重建：std::filesystem::space 的 available >> 20 截成 u32，出错返回 0xFFFFFFFF。平台替换已登记（0x00424330、0x00411D90）。exact。

## 0x00411E20 AngleBetween

象限选择（dy ≥ 0：dx < 0 从 180、下标 0、+5；dx ≥ 0 从 270、下标 0x59、−5；dy < 0：dx < 0 从 90、下标 0x59、−5；dx ≥ 0 从 0、下标 0、+5）、|(dy << 13) / 距离|、初值 9000、`jg` 不换（差值相同取后一项）与重建一致；距离为 0 时返回 0。
- 差异（diff 轮）：原版 dx、dy 与平方和是 32 位环绕（sub、imul、add），重建用有符号 int 运算（溢出为未定义行为）。已改为按 u32 环绕计算后再转 i32 交给 fild。修正后复核一致（exact 轮）。

## 0x00411FA0 Game::DrawPauseBanner
