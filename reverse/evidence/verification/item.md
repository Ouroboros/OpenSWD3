# 道具链表与道具作用核对记录（第 1 遍，2026-10-18）

## 0x0044D0F0..0x0044D6E0

- 0x0044D0F0 AddFlaggedItem：flagged 为 1 或数量为负时先找带位 0x8000 的同 id 节点（加后 i16 > 99 截到 99；> 0 返回，空项保持 1；≤ 0 删除，为 0 返回空，为负时把欠数带到普通节点）；flagged 为 0 或仍为负时找不带位的节点；都没有且数量为正时新建（空项数量 1，flagged 1 时置位 0x8000）并头插。差异（diff 轮）：读不到物品时的日志 "增加道具 沒有定義物品號碼(%d)"（0x004A73C0 + 0x004A6BA0，参数 id 零扩展）缺失，已补到两者共用的 NewNode。修正后通过（exact 轮）。
- 0x0044D2D0 AddItem：按 id 找节点，模式（u16）1 加数量、0 与 2 加待加，i16 有符号与 99 比较（到上限时清另一项）；模式 0 待加 ≤ 0 时并入数量、数量 ≤ 0 删除；模式 1 数量 ≤ 0 且待加 ≤ 0 删除；模式 2 待加 ≤ 0 且数量为 0 删除；其他模式不改数量；空项保持 1/0；新建时数量 ≤ 0 返回空，模式 0/2 记待加并置位 0x8000，模式 1 记数量，其他只插入。差异（diff 轮）：同一条读取失败日志缺失，已补（同上）。修正后通过（exact 轮）。
- 0x0044D4E0 MergePendingCounts（清位 0x8000、加待加、i16 > 99 截断）、0x0044D520 CopyItemList（头插得到反序副本）、0x0044D5A0 FreeItemList、0x0044D5D0 NewEmptyItem（0xFFDC、数量 1、"無"）、0x0044D620 UnlinkItem、0x0044D650 FindRoleItem（装备槽表 0x004C8AD0 到 hmod）、0x0044D680 FindItemOfKind（id & 0x3FFF 与 16 位参数比较）、0x0044D6B0 ItemAt：通过。
- 0x0044D6E0 ApplyObject：技能脚本 +0x18 位 15 时清倒下位；unk52 > 0x1B（无符号）且未倒下时只加三项生命值并按 16 位有符号比较截到上限；否则未倒下时按 unk3C：0 加生命值（截到上限）与八项属性，0x100 加上限与八项属性，0x200 按百分比回复后截断。差异（diff 轮）：0x200 的三项在汇编中都是两个有符号字 movsx 后的 32 位乘积再除以 100（0x0044D887..0x0044D8E4）；伪代码对前两项显示为先截成 16 位，重建照此截断，上限 × 百分比超过 32767 时回复量变负；改为 32 位乘积。修正后通过（exact 轮）。

## 0x0045D180..0x0045D2A0 战斗中加道具与排序

- 0x0045D180 AddOneItem：汇编 0x0045D18A 以 esi = 0x004A9940（表头本身是 0xB0 字节的静态节点，next 即第一个节点）起步。计数和 movsx 相加、≥ 0x63 不加；新节点插在表头后，pending 1 时置 kind 位 0x8000（0x0045D1F4 `or ah, 80h`）。差异（diff 轮）：id 0 时原版返回哨兵节点的记录 0x004A994C（全零），重建返回第一个节点的记录。调用者（0x00466F70、0x00467710、0x00469D20 指令 0x35）只取名字，重建的调用者都把 nullptr 读成空名字；改为 id 0 返回 nullptr。修正后通过（exact 轮）。
- 0x0045D250 SortItems（经过的节点 +6 清零，交换后从表头重来）、0x0045D2A0 SortSkills（四个 "無" 表头之后的条目，不清 +6）：通过。
