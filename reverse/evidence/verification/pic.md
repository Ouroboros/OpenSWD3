# 逐函数汇编验证：pic 模块

## 0x004014F0 RleCodec::Encode

- 第 1 轮（源码 bb1e648）：16 位与 8 位两条路径逐条对照——文件头（魔数 0x004CDE74、宽、高、格式；8 位写入原格式值）；行首标志 0x8000（16 位：首像素为填充色 0x004CDE78 或跳过色 0x004CDE20 时为 0；8 位只看填充色 0x004CD7B4）；同时等于两色的像素按跳过处理；字面段先写计数字再逐像素，遇填充或跳过即止；游程段计数 |0xC000（填充）或 |0x8000（跳过）；行长从 2 起计（行首）、每码 +2、字面像素 +2（8 位 +1），行尾 0 再 +2 后与标志相或写回行首（截为 16 位）；全图以 0 字结束。8 位游程延伸时把像素字节与整个 dword 比较，而该 dword 只被置为 1 与 3，结果相同。
- 原有 BUG：无。临时块大小 2·宽·高+0x2000 的写出已记偏差。
- 结论：通过。

## 0x004019A0 RleCodec::Decode

- 第 1 轮（源码 bb1e648）：差异两处——计数为 0 的码原程序以 16 位计数 `do … while (n != count)` 绕一圈重复 65536 次，重建写 0 个；输出块是调试堆新块（0xCD 填充），重建填 0。另有越界读写未设防。
- 修正：计数 0 按 65536；输出初值 0xCD；读到数据末尾之后视为 0、超出 宽·高 的像素不写（记偏差）。
- 第 2 轮：重新对照全函数——魔数比较为 32 位零扩展；格式掩码 0x3FFF；种类比较 `cmp bx, 8000h／0C000h` 为 16 位，0x4000 种类不写像素；字面 16 位逐字、8 位逐字节，之后读下一码；行尾码之后为下一行头；8 位写入填充、跳过色的低字节。
- 结论：通过。

## 0x00401B70 RleCodec::ConvertToDisplay

- 第 1 轮：魔数、宽高（任何格式都先写出）、格式掩码 0x7FFF、只有 0x10 继续；每个字面段原地经 0x004238B0（转换函数指针）转换，计数 0 不转换。差异：越界读写未设防。
- 修正：读到数据末尾即止（记偏差）。第 2 轮复核全函数：通过。

## 0x00401C70 RleCodec::ConvertTo16

- 第 1 轮：8 位图：新头格式 `(旧格式 & 0x8000) | 0x10`，行头为不带标志的行长（从 4 计起、每像素 +2、每个复制的码 +2），字面像素经调色板展开后转换，游程码原样复制；结尾多计 2 字节，从新工作块复制（0xCDCD）；释放调色板与旧数据，宽高不改。非 8 位：交给 0x00401B70 并取其宽高。字面计数以 32 位比较，计数 0 时原程序失控（越界）。差异：越界未设防。
- 修正：数据末尾即止，计数 0 不写像素（记偏差）。第 2 轮复核：通过。

## 0x00401E50 RleCodec::ConvertTileTo16

- 第 1 轮：瓦片前 0x200 字节为调色板，其后为 8 位 RLE；新头格式同上；行头写在每行之前的槽位，最后一个槽写 0 作结束；大小从 0xA 起计，最终多计 2 字节（0xCDCD），并截为 16 位后只复制这么多字节。字面计数以 16 位比较（码值即计数）。差异：越界未设防。
- 修正：数据末尾即止。第 2 轮复核：通过。
