# Painter 验证（第 1 遍）

## 0x00416D30 Painter::Init

0x00423400 失败返回 0；成功时裁剪区 x、y = 0，宽 = 0x4A0E78，高 = 0x4A0E7C，行地址表 0x4CC2F8 写入 高 项 行 × 跨度，调用 0x00416D90，返回 1。重建行地址以像素为单位（与重建画面指针的单位一致），表长保护见偏差表 0x00416D30 行。一致。exact。

## 0x00416D90 Painter::BuildBlitTables

表 0x4CD318（256 项）：0–3 0x418350/0x4185C0（复制，翻转同用），4/5 0x418840/0x418EB0（加亮），8/9 0x419570/0x41A3B0（透明度图），0xC–0xF 0x41F8D0/0x41FEA0（阴影），0x10/0x11 0x41B280/0x41B620（底色），0x14–0x17 0x41D340/0x41E5C0（半透明），0x18/0x19 0x41CCF0/0x41D010（边缘标记），0x1C 0x41B9F0（下淡），0x20/0x21 0x4208D0/0x420D70（缩放发光），0x24–0x27 0x421230/0x421540（剪影），0x28–0x2B 0x421850/0x421BE0（灰化），0x2C/0x2D 0x422030/0x4223A0（减暗），0x30–0x33 0x422730/0x4229C0（涂抹），0x80/0x81 0x4176D0/0x4177D0，0x84/0x85 0x417840/0x417E40，0x88 0x417EC0，0x94 0x417950。重建各模式常量与 Blit 函数的地址注释逐项相符，其余槽为空（调用见偏差表 0x004170E0 行）。一致。exact。

## 0x00416F10 Painter::LockSurface、0x00416F60 Painter::UnlockSurface

原版经 IDirectDrawSurface::Lock（vtable +0x64，DDSD 0x7C 字节）取内存，跨度 >> 1 存入 0x4CDE2C；Unlock（+0x80）。重建为模拟表面，记入偏差表平台替换行。exact。

## 0x00416F80 Painter::SetClip

左 < 0、上 < 0、右 > 屏宽、下 > 屏高 时返回 0；否则裁剪区 x、y、宽 = 右 − 左、高 = 下 − 上，返回 1。一致。exact。

## 0x00416FF0 Painter::SetClipClamped

左、上夹到 ≥ 0，右、下夹到 ≤ 屏宽、屏高，写裁剪区，恒返回 1（调用方不判断，0x0045AF90 原样返回）。一致。exact。

## 0x00417050 Painter::DrawOutline

模式 | 0x24（剪影）依次画在 (x+1,y+1)、(x−1,y−1)、(x−1,y+1)、(x+1,y−1)，返回最后一次的结果（无调用方使用）。一致。exact。

## 0x004170E0 Painter::DrawPicture

源首字 0xFFFF 且无调色板时置 0x80000000；模式 & 0xFFFC == 0x14 时透明度 ≤ 0 不画、> 0xF 时模式 &= 0x80000003。缩放比例、剪切步长清 0。缩放高 S 非 0：S ≤ 高 时比例 (高 << 10) / S − 0x400，否则 (高 << 10) / S 并置放大；行 = S；上裁 行 = S − 裁上 + y − 1、上跳 = 裁上 − y；下裁（行 + y ≥ 裁高 + 裁上）下跳 = 行 − 裁高 − 裁上 + y、行 = 裁高 − y + 裁上 − 1；剪切为 0 时置 1。不缩放：行 = 高；上裁 行 = 高 + y − 裁上；下裁 下跳 = 高 + y − 裁高 − 裁上、行 = 裁上 + 裁高 − y；剪切为 0 时横向裁剪后画。剪切路径：方向 剪切 > 0 时 −1 否则 1，步长 (|剪切| << 10) / (S 或 高)，横向裁剪同。画：目标 = 行表[y] + 2x，末行 = 目标 + 行表[行]，跨度；翻转时上跳 = 下跳、跨度取负、目标 = 末行；非 RLE 镜像时左跳 = 宽 − 左跳 − 1；非 RLE 源行 = 源 + (左跳 + 宽 × 上跳)（无调色板 × 2）；抖动相位 (y + 0x1E0) % 3；调用表[(u16)模式 + (RLE ? 0 : 0x80)](x, y, 宽, 高, 参数)。最后清 8 个选项（0x4CD300/304/30C/71C、0x4CDBE0、0x4CD75C、0x4CD718、0x4CC2F0，对应 DrawOptions 的 8 个字段）。放大标志与剪切方向只在各自路径写入，重建保留；其余位置字段在调用前都重新写入（RLE 的 blit 不读源行）。
- 差异（diff 轮）：源为空时重建直接返回而不清选项（原版解引用空指针）。已改为照常清零；不绘制时的返回值记入偏差表（调用方 0x004490C0、0x004831C0 只复用寄存器）。复核一致（exact 轮）。

## 0x004174D0 Painter::DrawTile16、0x00417530 DrawTile16Keyed、0x004175B0 DrawTile8、0x00417650 DrawTile8Keyed

目标 = 画面 + 行表[y] + 2x，16 行，每行跨度前进。16 位：每行 32 字节（双字成对自后向前，结果相同）；键色版逐像素与 0x4CD784 低字比较，不同才写；8 位：经调色板 0x4CD764 取色，键色版索引 1 不写。返回值无调用方使用。一致。exact。

## 0x004176D0 Painter::BlitRawCopy、0x004177D0 BlitRawCopyMirrored

有调色板：行数 0x4CD740 次，每行宽 0x4CD74C 个索引经调色板写入，源前进 宽 0x4CD74C 外再补到图宽，目标前进 跨度（0x4A0E74，翻转时不取负，从末行向下）。无调色板：同样按字复制（do-while，可见时行、宽 > 0）。镜像：只按 16 位，源每像素 −1，每行 + 2 × (宽 + 图宽) 字节，即逐行 + 图宽。一致。exact。

## 0x00417840 Painter::BlitRawKeyed、0x00417E40 BlitRawKeyedMirrored

有调色板：索引 1 不写；无调色板：与 0x4CD784 低字比较。镜像：只按 16 位，00417E8F 以 32 位 eax（高半字 0）与整个 0x4CD784 比较，重建同样与整对比较。前进同复制。一致。exact。

## 0x00417950 Painter::BlitRawTranslucent

透明度 −1 后 × 4 作为栈上 16 项跳转表下标；与 0x4CD784 低字相同的像素跳过。表项 k 的 4 位自高到低决定 >>1、>>2、>>3、>>4 各取源或目标（0x417A8D：D D D S … 0x417D6C：S S S D），k = 0 不写（0x417DA7），k = 15 复制源（0x417DA2，DrawPicture 把 > 15 改为复制，实际不可达）；各项与 0x4CD788/78C/790/794 相与后相加，存低字。32 位读取的高半字经掩码（各通道右移后保留通道内位）不进入低字。重建 Blend(目标, 源, 透明度 − 1) 按位 8/4/2/1 选取，≤ 0 保留目标、≥ 15 取源。镜像槽 0x95 为空（偏差表 0x004170E0 行）。一致。exact。

## 0x00417DE0 Painter::BlendPairsWithColor

每个双字 = (值 >> 1 & 0x4CD788) + (颜色 >> 2 & 0x4CD78C) + (值 >> 3 & 0x4CD790) + (值 >> 4 & 0x4CD794)，个数 = 第三参数 >> 1（调用方见 0x00414E50 等，各自已验证）。一致。exact。

## 0x00417EC0 Painter::BlitRawGradient

颜色 = 源首字（零扩展存在栈上 var_4，按双字读）；跳转表下标从 0x3C（第 15 项，复制）起；每像素按当前项与颜色混合（无键色判断，表同 0x00417950：第 0 项不写），每行后行计 + 1，大于 高 >> 4 时归零、下标 − 4。重建 Blend(目标, 颜色, 级别) 级别从 15 递减。级别低于 0 的情况见偏差表。一致。exact。

## 0x00418350 Painter::BlitCopy

波浪 0x4CD724 非 0 时：起点 0x84 × (模式 − 1)，位置 = 相位 0x4CD758 + 起点，终点 起点 + 0x84；源头 +6 & 0x10 时：跳过上跳行（每行加 行首字 & 0x7FFF）；逐行先推进波浪（位置 + 4 ≥ 终点 时回起点，目标 += 表 0x4A06A8[位置/4]），行首字为 0 或行计数超过 0x4CD740 结束；行内（行首后 2 字节起）：字面段（& 0xC000 为 0）与透明段（其余）计数 & 0x3FFF 为 0 结束本行；左跳 0x4CD750 前的部分跳过（字面段跳过其像素），可见部分字面段复制、透明段只移目标，到 宽 + 左跳 时结束本行；下一行目标 = 本行未加波浪的目标 + 带符号跨度 0x4CC2EC；结束后相位 + 4，≥ 0x84 回 0。重建 ForEachLine（signedPitch）/ForEachRun 逐项对应（Word 以字为下标，格式字为第 3 字即 +6；表外偏移见偏差表第 15 行）。一致。exact。

## 0x004185C0 Painter::BlitCopyMirrored

起始列 = 图宽 − (宽 + 左跳)（重建 mirrorStart），目标从 目标 + 2 × 宽 起向左写（> 4 像素时双字经 ROL 16 交换半字，等于逐像素反向）；行、波浪、裁剪同 0x00418350，结束后不推进波浪相位（advanceWave = false）。一致。exact。
