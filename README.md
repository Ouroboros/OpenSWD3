# OpenSWD3

《軒轅劍參 雲和山的彼端》（v1.02 DVD 版）的重制执行程序。

它取代原版的 `swd32.exe`，读取你已安装的原版游戏资料，在现在的 Windows 上直接运行。剧情、战斗、数值与各种规则都和原版一样，连原版的小 BUG 也保留；会让游戏崩溃的问题则已修正。

本项目不含任何游戏资料，需要你已有原版游戏。

主页：<https://ouroboros.github.io/OpenSWD3/>

## 和原版相比

| 方面 | 原版 | 重制版 |
| --- | --- | --- |
| 游戏目录 | 由安装程序写入的目录 | 游戏资料和存档可以放在任意目录，目录名可以有中文 |
| 字体 | 需要系统装有細明體 | 自带字体 |
| 窗口 | 640×480 独占全屏 | 窗口运行，任意缩放，`Alt+Enter` 切换全屏，记住窗口大小 |
| 切到其他程序 | 游戏暂停 | 继续运行 |
| 画面 | 每 35 毫秒画一帧，固定 640×480 | 可按显示器刷新率平滑显示，地图可填满宽屏（见「设置」） |
| 启动画面 | 每次都显示 | 可以跳过，直接进入标题画面（见「设置」） |
| 隐藏道具 | 没有提示 | 可显示提示箭头（见「设置」，默认关闭） |
| 地图全景 | 没有 | 地图上按 Tab 打开当前地图的全景大地图，标出主角位置和各出入口通往的地方，可缩放、拖动，再次打开时保持上次的缩放 |
| 状态页 | 只显示等级、经验与四项属性 | 另显示閃躲、異常、默契、反應与绝技点（学下一个绝技的进度） |
| 商店买卖数量 | 左右键每次加减 1 | 按住 Shift 再按左右键，数量直接减到 0 或加到最多（卖：全部；买：银币够、合计不超过 99） |
| 武器说明 | 只有文字说明 | 末尾显示武器成长带来的伤害加成（当前与成长满时） |

每一处和原版不同的行为都记录在 [deviations.md](reverse/analysis/deviations.md)。

## 安装与运行

1. 准备好原版游戏目录，例如 `E:\Game\swd3`。
2. 解压后得到 `OpenSWD3` 文件夹，里面有 `swd3r.exe`、`asset` 文件夹和设置文件 `swd3r.toml`。可以整个放在任意位置，也可以把里面的东西放进游戏目录。
3. 如果没有放进游戏目录，用记事本打开 `swd3r.toml`，在 `[paths]` 里写上游戏目录：

   ```toml
   [paths]
   data_dir = 'E:\Game\swd3'
   ```

4. 运行 `swd3r.exe`。

## 设置

exe 旁边有两个设置文件：

- `swd3r.toml`：你自己的设置。程序只读不改，注释和顺序都保留。
- `swd3r.default.toml`：程序自动保存的设置，包括游戏里改的设置、按键和退出时的窗口大小。

同一项两个文件都写了时，以 `swd3r.toml` 为准，这时在游戏里再改只在当次有效。`swd3r.toml` 里每一项都带着说明，默认被 `#` 注释掉，删掉行首的 `#` 就会生效。值写错或没写时取默认值，写错的会在日志里记一条警告。

下面的例子除了游戏目录，写的都是默认值。

### 游戏目录

```toml
[paths]
data_dir = 'E:\Game\swd3'
save_dir = 'E:\Game\swd3\save'
```

- `data_dir`：原版游戏目录。不写时用当前目录，所以把 exe 放进游戏目录就不用写。相对路径以 exe 所在的目录为准。
- `save_dir`：存档目录。不写时和原版一样存在游戏目录的 `save` 里。
- 路径用单引号括起来，反斜杠照写；用双引号时反斜杠要写成 `\\`。

### 窗口

```toml
[window]
width = 1280
height = 960
maximized = false
```

- `width`、`height`：窗口的宽和高，至少 640×480。画面保持原来的比例，尽量填满窗口，比例不同时留黑边。
- `maximized`：启动时是否最大化。
- 这三项不写时，用上次退出时的窗口大小。游戏里按 `Alt+Enter` 切换全屏。

### 画面

```toml
[display]
smooth_motion = true
vsync = true
frame_rate = 0
render_scale = "auto"
wide_map = true
item_hints = false
```

- `smooth_motion`：平滑畫面。游戏逻辑仍和原版一样每 35 毫秒走一步，移动、淡入淡出等动态在两步之间按显示器刷新率连续画出，高刷新率显示器更流畅。写 `false` 时和原版一样每 35 毫秒画一次。
- `vsync`：垂直同步。等显示器刷新再显示，消除画面撕裂。
- `frame_rate`：每秒最多画几帧，可写 30～1000；`0` 表示不限，开着垂直同步时就跟随显示器刷新率。只在平滑畫面开启时有效。
- `render_scale`：平滑畫面按几倍精度绘制，可写 1～8。倍数越高，镜头和人物移动越细，也越耗 CPU（2 倍约为 1 倍的 3～4 倍）。`"auto"` 按窗口大小取能完整显示的最大倍数，最多 4 倍。只在平滑畫面开启时有效。
- `wide_map`：地图填满宽屏窗口，能看到更大范围，对话框仍在中间。菜单、战斗、存档等画面仍是 640×480，两边留黑边。
- `item_hints`：道具提示。地图上看不见、但调查后能拿到道具或银币的地方，显示一个跳动的箭头（包括鼠标移上去不变手形、只能面对它按键调查的地方），还没打开的罐子、宝箱也显示。能调查时才显示，拿走后消失。

这六项也能在游戏里改：标题画面的「環境設定」，或游戏中按 Esc →「設定」→「顯示設定」。

### 游戏

```toml
[game]
launcher = true
auto_combo = false
running = true
debug = false
```

- `launcher`：启动时先显示启动画面。写 `false` 时直接进入标题画面。游戏里在「設定」第一行切换。
- `auto_combo`：自動連擊。自动战斗时，戴着「連擊」饰品（武聖手鐲、姜公膽）且体力足够的角色自动使用「連擊」，体力不够时照常普通攻击。游戏里在「設定」→「戰鬥設定」切换。
- `running`：地图上默认跑步，写 `false` 是走路。游戏里按 R 切换时会记下来，下次启动照旧。
- `debug`：调试模式，见下面的「调试模式」。

`[game]` 里还有音量、文字速度、战斗速度和按键（`[game.keys]`），和原版「環境設定」里的一样，在游戏里改就行。第一次启动时，这些设置会从游戏目录的 `Env.dat` 导入一次。

### 日志

```toml
[logging]
path = "logs/swd3r.log"
level = "debug"
```

- `path`：日志的位置和文件名。每次启动写一个新文件，文件名后面加上启动时间和进程号，例如 `logs/swd3r-2026-10-26_14-32-05-127840.log`。相对路径以 exe 所在的目录为准。
- `level`：记录多详细，从多到少是 `trace`、`debug`、`info`、`warning`、`error`、`critical`。

## 隐藏秘籍

以下都是原版就有的隐藏功能。

### 特殊名字

新游戏给前两位角色取名时，输入下面的名字，取名完成后对应角色的数值会改变。名字必须完全一致，只在取名时生效一次。

第一位角色（默认「賽特」）：

| 名字 | 效果 |
|---|---|
| 何然 | 力量、耐力、智慧、敏捷都变成 25 |
| 輔子徹 | 力量、耐力、智慧、敏捷都变成 30 |
| 楊坤碩 | 力量 50，生命和生命上限 200 |
| 鑄石子 | 耐力 100，体力和体力上限 300 |
| 樂樂 | 智慧 70，魔法和魔法上限 250 |
| 大米 | 智慧 100，所有属性「損20%」（属性伤害多受 20%） |
| 古月聖 | 所有属性「抗50%」（属性伤害只受一半） |
| 寧采臣 | 耐力、智慧、敏捷各减 5，力量减 10，金钱变成 500 |
| 燕赤霞 | 耐力、体力、体力上限都变成 0（原版此时打开菜单会崩溃，本程序已修正） |

第二位角色（默认「妮可」）：

| 名字 | 效果 |
|---|---|
| 江如紅 | 智慧 100，魔法和魔法上限 300 |
| 真夢 | 耐力 100，体力和体力上限 300 |
| 紅珊瑚 | 力量 50，生命和生命上限 200 |
| 紋錦 | 所有属性「抗70%」（属性伤害只受约三成） |
| 小倩 | 智慧、魔法、魔法上限都变成 5 |

### 随时可用的按键

| 按键 | 作用 |
|---|---|
| F8 | 暂停／继续游戏 |
| P（地图上） | 截图，存到游戏目录的 `ScrnShot` 文件夹 |
| Tab（地图上） | 打开／关闭大地图（游戏暂停）；滚轮或 `+` `-` 缩放，拖动或方向键移动，Home 回到主角，Esc 也能关闭 |
| P（战斗中） | 截图，和地图上一样存到 `ScrnShot` 文件夹 |

### 调试模式

在 `swd3r.toml` 的 `[game]` 里写上 `debug = true` 打开调试模式。之后：

- 战斗中的调试键直接可用，战斗画面会显示调试信息。
- 地图上同时按住 右Ctrl + 右Shift + Home + End，才会开启地图的调试键。开启状态记在剧情旗标里，会随存档保存：之后读这个存档或它后来的存档，不用再按就能用，也没有办法关掉（和原版一样）。

地图上（只在没有对话时）：

| 按键 | 作用 |
|---|---|
| F12 | 打开剧情旗标查看画面 |
| Ctrl+S／Ctrl+L | 随时打开存档／读档画面 |
| Ctrl+F9 | 快速模式（对话自动跳过），再按一次关闭 |
| Ctrl+F1／Ctrl+F2 | 显示／隐藏调试文字与地图格子标记 |
| Ctrl+F3 | 可以穿过障碍物，再按一次恢复 |
| Ctrl+Tab+小键盘 +／- | 调整地图动画的速度 |
| Ctrl+Q | 立刻退出游戏 |
| F4 | 作弊对话框（只限 Windows）：增删物品、四位角色的技能，修改角色属性与剧情变量 |
| F6 | 大部分物品与装备各增加 10 个 |
| F7 | 金钱增加 1000 |

战斗中（按住 Ctrl）：

| 按键 | 作用 |
|---|---|
| Ctrl+F1 | 显示／隐藏敌人的调试信息 |
| Ctrl+X | 攻击不扣血（敌我都是），再按一次恢复 |
| Ctrl+Z | 我方全员生命、魔法、体力补满，怒气补满，攻击 9900、防御 155、敏捷 200 |
| Ctrl+W | 敌人全灭 |
| Ctrl+K | 下一击为「強攻擊」 |
| Ctrl+D／Ctrl+F | 我方全员受到 80／500 点伤害 |
| Ctrl+V | 敌人全员受到 10 点伤害 |
| Ctrl+F2 | 切换「絕對靈契」／「正常靈契」 |
| Ctrl+F9 | 快速模式（对话自动跳过） |
| Ctrl+C | 中止正在施放的法术 |
| Ctrl+F3／Ctrl+F5 | 停止／重新播放战斗音乐 |
| H／J（不按 Ctrl） | 所有角色和敌人向右／向左移动 10 像素 |
