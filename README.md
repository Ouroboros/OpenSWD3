# OpenSWD3

《軒轅劍參 雲和山的彼端》（v1.02 DVD 版）的重制执行程序。

它取代原版的 `swd32.exe`，读取你已安装的原版游戏资料，在现在的 Windows 上直接运行。剧情、战斗、数值与各种规则都和原版一样，连原版的小 BUG 也保留；会让游戏崩溃的问题则已修正。

本项目不含任何游戏资料，需要你已有原版游戏。

## 和原版相比

- 一个 exe 直接在现在的 Windows 上运行：不需要光盘、虚拟光驱和安装程序，也不用装 DirectX 或其他运行库。
- 窗口运行，可以任意缩放，`Alt+Enter` 切换全屏，下次打开保持上次的窗口大小。
- 切到其他程序时游戏不会暂停。
- 修正原版在 Windows 10 及以后走路、动画变慢卡顿的问题。
- 支持高刷新率显示器，画面更流畅（可在「顯示設定」里关闭）。
- 地图画面填满宽屏窗口，能看到更大范围的地图（可在「顯示設定」里关闭）。
- 自带字体，不需要系统里装有細明體。
- 修正原版改过按键后，下次启动设置和按键被重置的问题。
- 第一次启动自动沿用原版的音量、按键等设置；走路／跑步状态会记住。
- 可以跳过启动画面，直接进入标题画面（关闭「啟動畫面」）。
- 「啟動畫面」「顯示設定」在标题画面的「環境設定」和游戏中的「設定」里都能调整，设置改了立即保存。
- 战斗中用键盘操作时，指令菜单不会跳到鼠标的位置。
- 战斗中按一下指令快捷键只对当前角色生效，不会连到下一个行动的角色。
- 游戏资料和存档可以放在任意目录，目录名可以包含中文。
- 游戏崩溃或卡住时会自动记录，回报问题时附上 `logs` 文件夹即可。

## 安装与运行

1. 准备好原版游戏目录，例如 `E:\Game\swd3`。
2. 解压后得到 `OpenSWD3` 文件夹，里面有 `swd3r.exe`、`asset` 文件夹和设置文件 `swd3r.toml`。可以整个放在任意位置，也可以把里面的东西放进游戏目录。
3. 如果没有放进游戏目录，用记事本打开 `swd3r.toml`，在 `[paths]` 里写上游戏目录：

   ```toml
   [paths]
   data_dir = 'E:\Game\swd3'
   ```

4. 运行 `swd3r.exe`。

## 设置

exe 旁边有两个设置文件：

- `swd3r.toml`：你自己的设置，程序不会改动它。
- `swd3r.default.toml`：游戏自动保存的设置，例如游戏里调整的音量、按键、显示设定和窗口大小。

两个文件写了同一项时，以 `swd3r.toml` 为准。`swd3r.toml` 里列出了所有可设置的项目和说明，去掉需要项目前面的 `#` 再修改即可。

## 和原版不同的地方

- 原版的 MIDI 音乐不会播放（游戏中的 MP3 音乐和影片正常）。

每一处和原版不同的行为都记录在 [deviations.md](reverse/analysis/deviations.md)。
