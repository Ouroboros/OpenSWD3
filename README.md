# swd3-rebuild

《軒轅劍參 雲和山的彼端》（v1.02 DVD 版）的重制执行程序。

它取代原版的 `swd32.exe`，读取你已安装的原版游戏资料，在现在的 Windows 上直接运行。剧情、战斗、数值与各种规则都和原版一样，连原版的小 BUG 也保留；会让游戏崩溃的问题则已修正。

本项目不含任何游戏资料，需要你已有原版游戏。

## 和原版相比

### 直接在新系统上运行

- 不需要光盘，也不需要虚拟光驱。
- 不需要安装 DirectX、旧版音效或影片组件，也不需要额外安装运行库，一个 exe 就能运行。
- 不需要原版的安装程序。

### 画面与窗口

- 以窗口运行，画面按原版比例放大，填满窗口，比例不合时两侧留黑边。
- 窗口可以任意拉大缩小（最小 640×480），拖动窗口时游戏不会停住；`Alt+Enter` 切换全屏。
- 下次打开时窗口保持上次关闭时的大小。
- 切到其他程序时游戏照常运行、继续播放声音，只有最小化时才暂停。
- 自带游戏字体，不需要系统里装有細明體。

### 更流畅

- 原版在 Windows 10 及以后的系统上走路、动画会明显变慢、一顿一顿的，这里已修正，速度与原版设计的一致。
- 平滑画面：游戏本身仍按原版每 35 ms 一帧运行，速度和规则不变；地图上的镜头、人物、天气与落叶等特效、聚光灯和对话头像在两帧之间按显示器刷新率插值重画，60 Hz、144 Hz 等显示器上移动连贯。画面最多比实际状态晚一帧。
- 细于一个像素的移动：窗口够大时，地图按 2～4 倍绘制，镜头和人物可以停在半个、四分之一个像素上，移动更细腻；每个原版像素仍画成整块，画面内容与原版一致。
- 支持垂直同步和每秒帧数上限。
- 以上几项可以在游戏中按 Esc →「設定」→「顯示設定」调整，也可以写在设置文件里。战斗画面暂时仍是每 35 ms 一画。
- 按 R 切换走路／跑步时一按只切换一次，不再有原版那 0.2 秒的停顿。

### 设置与存档

- 设置保存在 exe 旁边的文本文件里，用记事本就能修改。
- 第一次启动时会自动沿用原版的音量、按键等设置。
- 修正原版的按键设定问题：原版改过按键后，下次启动所有设置和按键都会被重置。
- 走路／跑步状态会记住，下次启动沿用。
- 游戏资料可以放在任意目录，存档也可以单独放到其他目录。
- 目录名称可以包含中文。
- 游戏运行时，存档等文件可以同时用其他程序打开或备份。

### 出问题时有记录

- 每次运行都会在 `logs` 文件夹里留下记录。
- 游戏崩溃或卡住时会自动记下当时的情况，回报问题时附上 `logs` 文件夹里的文件即可。

## 安装与运行

1. 准备好原版游戏目录，例如 `E:\Game\swd3`。
2. 把 `swd3r.exe` 和 `swd3font.bin` 放进同一个文件夹，可以直接放进游戏目录。
3. 如果没有放进游戏目录，在 exe 旁边新建一个文本文件 `swd3r.toml`，写上游戏目录：

   ```toml
   [paths]
   data_dir = 'E:\Game\swd3'
   ```

4. 运行 `swd3r.exe`。

## 设置

exe 旁边有两个设置文件：

- `swd3r.toml`：你自己的设置，程序不会改动它。
- `swd3r.default.toml`：游戏自动保存的设置，例如游戏里调整的音量、按键、显示设定和窗口大小。

两个文件写了同一项时，以 `swd3r.toml` 为准；所以在 `swd3r.toml` 里写了的项目，游戏里改过后下次启动会恢复成 `swd3r.toml` 的值。所有可设置的项目和说明见本仓库的 [swd3r.toml](swd3r.toml)，复制过去，去掉需要项目前面的 `#` 再修改即可。

## 和原版不同的地方

- 原版的 MIDI 音乐不会播放（游戏中的 MP3 音乐和影片正常）。
- 原版开始画面里点不到的“输入姓名”对话框没有保留。

每一处和原版不同的行为都记录在 [deviations.md](reverse/analysis/deviations.md)。
