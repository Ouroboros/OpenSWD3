# 原版角色位置采集

这个一次性工具用于确认原版普通世界绘制 `0x00413910` 收到的蓝衣、红衣酒客
角色状态。它只读取 GUID `248/249` 的角色坐标、动作偏移和相机位置，不修改原版
内存、数据文件或游戏输入。

便携目录位于 `build/vm/role-placement-oracle/`。把整个目录复制到原版游戏目录下，
先正常启动 `swd32.exe` 并进入蓝衣角色仍然可见的剧情画面，再双击
`role-placement-oracle.exe`。工具只 attach 这个已经运行的进程，不会启动、恢复、
暂停或关闭原版。让该画面保持数秒后，可在采集窗口按 `Ctrl+C`；工具 detach 后原版
继续运行。

结果写在游戏目录：

```text
role-placement-oracle.tsv
```

该 TSV 每 100 ms 记录一次两个目标角色，足以区分地图初始坐标、剧情移动、角色
细偏移、动作帧偏移和相机偏移。

## 已取得的基准

有效采集共 71 组稳定样本，两个角色在所有样本中保持：

| GUID | 世界坐标 | action/variant | 绘制偏移 | TSW 帧 | mode | 相机 | 目标坐标 |
|---:|---:|---:|---:|---:|---:|---:|---:|
| 248 | `416,416` | `623/4` | `27,48` | `188/4` | `1` | `80,128` | `309,240` |
| 249 | `320,432` | `623/5` | `5,46` | `188/8` | `0` | `80,128` | `235,258` |

GUID 248 的 mode bit 0 表示水平反转，GUID 249 保持正向。该结果已进入真实数据集成
回归；后续无需为这个位置问题再次启动原版。
