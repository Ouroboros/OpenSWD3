# 世界角色 PATH 指令循环：`0x00405500..0x00406709`

状态：`sub_405500` 的 opcode `0/4/5/7/8` 已按汇编实现并接入；`sub_406580`
已完成全函数第二次核对；其余 32 个 opcode 仍为显式未实现边界

来源：`swd3.exe.lst` 完整汇编；IDA 伪码仅作导航

## 1. 当前有限闭环

`sub_405500` 有 37 个 jump-table 分支。本轮没有试图一次猜完全部解释器，只恢复普通
角色能够形成独立运行闭环的五项：

| opcode | 汇编入口 | 当前精确行为 |
|---:|---:|---|
| 0 | `0x00405EB1` | 把角色 `path_word_index` 清零并返回 |
| 4 | `0x0040556E` | 把下一 word 写入 `path_wait_remaining`，光标前进 2 word，继续同一次解释 |
| 5 | `0x00405F6E` | 等待值非零则减一，否则光标前进 1 word；两条路径都立即返回 |
| 7 | `0x0040557B` | 以随后两个 word 为目标格调用 `sub_406390`，光标前进 3 word，继续同一次解释 |
| 8 | `0x0040559F` | 角色坐标对齐时调用 `sub_406580`；活动/暂停时返回，路线结束时前进 1 word、清 flags bit 26 后继续 |

PATH 命令地址严格沿用原式：

```text
relative = u32(PATH + 0x200 + role.path_data_id * 4)
command  = PATH + 0x200 + relative + role.path_word_index * 2
```

现代 owner 只在文件边界之外增加显式错误状态，不改变有效数据的 word 宽度、光标单位或
同帧 fallthrough。遇到未恢复 opcode 时不推进光标、不伪造副作用；SDL 只记录一次警告，
后续模块切片再继续恢复。

## 2. `sub_406580` 的 72 槽运动准备

该 helper 固定扫描 72 个、每个 `0x21C` 字节的活动对象槽。角色索引匹配且槽 `+0x1B`
低半字节为 1 时处理普通路线；低半字节为 2 时直接让当前 PATH 帧等待。

普通路线的顺序为：

1. 角色 `interaction_gate == 1` 时只给槽路径游标置 `0x8000` 帧门并返回。
2. 以 `cursor & 0x7FFF` 读取 `+0x1C` 起的方向字节；`0xFF` 用 `0xFF` 清空整个槽并
   返回机器值 2。
3. stall `+0x1A <= 8` 时用 `0x60000000` 掩码探测地表，否则用 `0x40000000`。
4. 无论是否阻挡，都先给游标置帧门、stall 加一、清零 `+0x16/+0x18` 步长。
5. 当前方向未阻挡时再清游标帧门、把 stall 清零，并按方向表写入 4 像素有符号步长：

```text
X = [ 4, 0,-4,-4,-4, 0, 4, 4 ]
Y = [ 4, 4, 4, 0,-4,-4,-4, 0 ]
```

没有找到匹配槽时，原 helper 走诊断出口并返回 2；因此 opcode 8 同样前进并继续解释。
现代实现保留返回合同，省略无行为作用的旧诊断字符串格式化。

## 3. 调用者门与运行时接线

本轮同时恢复 `sub_405430` 中进入普通 PATH 解释器的可执行门：角色从索引 1 开始扫描，
必须带 flags bit 15、不能带队伍 bit 7、不能带 bit 31、`interaction_gate != 1` 且
`path_data_id != 0`。队伍 bit 7 路径仍由已经恢复的 `sub_406960` owner 在同一 app
阶段处理；app 按原 `sub_405430` 从角色索引 1 起逐角色选择普通或队伍 owner，不把两类
角色拆成两轮扫描。

普通 PATH owner借用进程期 A* 节点池、真实 PATH.DAT 映射、地图表面格和
`LegacyWorldMapRolePathState` 的 72 个活动槽。opcode 7 生成的槽由既有
`0x004121A1..0x004124D1` 帧循环消费；下一帧 opcode 8 再准备四像素步长，由此形成
“请求路线 → 帧内移动 → 终点清槽 → 下一指令”的最小闭环。

`sub_405430` 中 bit 31/interaction 分支的额外地表恢复，以及 `sub_405500` 其余 32 个
opcode 尚未在本轮实现，因此整个函数不能标记为完成。

路径差异。
