# 战斗运行时固定对象销毁 `0x0045EA30`

状态：`platform_adapted`、`unit_tested`、`fixed_state_tested`、`caller_reclaimed`。

## 1. 范围与调用图

权威LST完整主体为`0x0045EA30..0x0045EA70`，从`proc`到`endp`共33行、21条实际指令、3个call、2个跳转、2个局部标签，没有外部`FUNCTION CHUNK`。

唯一caller为已关闭总销毁`0x004251B0`。三个call分别是：

1. 已关闭战斗渲染资源清理`0x00433D70`；
2. 组A对象析构`0x00475180`；
3. 组B对象析构`0x00476A60`。

渲染资源清理已直接组合typed实现。两类对象析构仍属于各自后续工作包，当前只以两类窄端口保留完整对象token、索引和EAX/ECX/EDX返回，不提前宣称其内部关闭。

## 2. 固定组A十对象

渲染清理返回后，ESI固定从`0x005029D0`开始。每轮以当前ESI作为this调用组A析构，再执行u32加`0x2F34`，与固定尾地址`0x005201D8`按signed `<`比较。

因此循环精确执行十次，对象token依次为：

```text
0x005029D0 + index * 0x2F34, index = 0..9
```

循环不读取动态角色数，不因析构返回值停止，也不增加现代上限。每次callee完整返回寄存器可以被下一次调用覆盖；组A最后一次返回还会被首个组B析构覆盖。

## 3. 固定组B八对象与尾返回

组A结束后ESI无条件改为`0x00525508`。每轮以当前ESI作为this调用组B析构，再执行u32加`0x2B28`，与固定尾地址`0x0053AE48`按signed `<`比较。

循环精确执行八次，对象token依次为：

```text
0x00525508 + index * 0x2B28, index = 0..7
```

第八次组B析构返回后，函数只恢复ESI并`retn`；pop不改EAX/ECX/EDX，因此完整尾返回来自最后一个组B析构。typed结果显式保留三项寄存器，不把EAX规范化为bool或调用计数。

## 4. 渲染资源唯一owner

首call直接复用`LegacyBattleStartupState::render_geometry`唯一存储，严格执行：

1. 非零辅助buffer token调用释放端口后清零；
2. 非空surface行偏移释放；
3. 非空primary行偏移释放。

即使三项渲染资源都为空，固定10次组A和8次组B析构仍全部执行。对象地址继续使用`compat::u32` token，不转换为宿主指针。

## 5. 总销毁caller回收

已关闭总销毁原本把本函数保留为通用地址枚举操作。该枚举值现只保留reserved数值槽；总销毁在字体与前一资源释放之后直接调用typed战斗运行时销毁，再继续下一固定资源阶段。

SDL关闭端持有唯一战斗启动/渲染状态并调用同一typed入口。两类尚未关闭析构callee继续由平台窄端口承接；当前没有战斗对象宿主后端时返回零寄存器，但固定18次调用、渲染清理和总销毁顺序不被省略。

## 6. 验证与动态差分

定向测试覆盖非空/空渲染资源、辅助token释放、三项资源清零、完整10/8对象token序列、固定步长/尾地址、第八个组B完整寄存器返回，以及总销毁中typed调用的精确位置。应用生命周期、窗口销毁和平台集成测试共同锁定caller顺序。

当前缺少原版10个组A对象、8个组B对象、两类析构内部资源、allocator释放副作用和寄存器联合捕获后端，`original_diff_verified`为`blocked_runtime_oracle`。
