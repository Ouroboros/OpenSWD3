# 绘制系统菜单五个标签、各页内容并处理按键设置 `0x0044C160`

状态：`platform_adapted`

## 1. LST锁

权威范围为`swd3.exe.lst`的`0x0044C160..0x0044CFF2`，1697行，无外部FUNCTION CHUNK。入口由`0x0043B480`的G05回调组和`0x00444FC0`回调表保存。

原版Big5静态文字确认五个顶层标签依次为“存档”“读取”“记载”“设置”“离开”。函数每帧先计算文字颜色、准备外框、绘制五个标签；选中标签使用原色和左上偏移一像素，其余标签分别执行一次颜色调整。

## 2. 各页面结果

- 不可存档提示：绘制“目前无法存档”。
- “记载”页：绘制页面外框；总数signed大于5时分别消费滚动标志低/高半字节并绘制float比例滚动条；目录owner非零时按`page_start + index`绘制所有signed正可见项。
- “设置”页：绘制音效、音乐、置换空间、地图效果、文字速度、战斗速度、按键设置及版本文字；音效、音乐、战斗速度各绘12格，置换空间3格，地图效果2格，文字速度5格。地图效果每格重新查询service 48，显示文字前再查询一次。
- 文字速度说明：严格映射“最快、快、适中、稍慢、慢”；“云和山的彼端”按当前长度每项复制两个字节到说明owner，倒计时按signed递减，归零后长度加一并写`2 * interval + 1`。复制源和随后终止符读取分别在原始访问点typed-stop，保留此前所有绘制与倒计时副作用。
- “离开”页：第0行显示“结束游戏”，第1行显示“重新开始”。确认框显示“目前进度将会消失”及对应问题、“确定”“放弃”；确认值signed达到30后发布向下递减的转场偏移并递增，signed达到60时先直接复用`release_legacy_system_menu`。
- 动作值1执行“结束游戏”：准备退出、清运行状态、发布退出请求、清flag 1并OR运行标志4。
- 动作值2执行“重新开始”：发布状态`0x80000003`并清三个工作区值，保留page kind。

页面绘制完成后按LST重新读取交互状态；绘制回调把状态改为按键设置时，同一帧继续执行按键页面，不能使用旧snapshot。普通mode 1/2最终返回重读后的mode；mode 2非“离开”页保留其提前返回残值。

## 3. 按键设置

原版16项功能依次为：上、下、左、右、进入介面、确定、取消、放弃、切换一、切换二、说明文、上一页、下一页、跑步、自动攻击、逃跑。静态绑定槽依次为`4,6,3,5,12,1,9,0,10,2,19,7,8,16,17,18`。

mode 5/6/7绘制16项功能和当前键名，并绘制“设置、放弃、恢复预设值”三项。mode 6绘制后切到mode 7；mode 7额外显示“请按一个键”，顺序执行按键查找和原始Backspace读取：

- Backspace且当前槽非`0xFF`时不改绑定，返回编辑页并播放样本`0x8B`。
- 旧按键latch非零时返回旧值并发布新采样。
- 与当前绑定相同则返回编辑页。
- 新键未被16项使用时写入当前槽、返回编辑页并播放`0x8B`。
- 新键与其他功能冲突时，选择冲突功能，把其槽写`0xFF`，保存被替换值，当前槽写新键并播放`0xB8`。
- 15个保留键`3A,45,46,43,44,57,58,64,65,66,B7,DB,DC,DD,19`各播放两次`0x8C`且不提交。

选择与16比较保持signed域；负值普通绘制继续生成原坐标。固定操作只允许16..18，在原坐标表读取点停止；mode 7的选择越界只在完成按键查找和Backspace读取后、首次读取16项静态槽时停止。键名只允许`0..255`，越界在对应功能文字已绘制后停止。

未关闭的外框、文字、面板、记载项和设置格绘制以最窄`LegacySystemMenuFrameCommand`流表达；命令携带完整七参画框顺序、原文字标识、坐标、颜色、float比例和动态值。已关闭的系统菜单释放直接调用typed函数，不保留opaque关闭命令。
