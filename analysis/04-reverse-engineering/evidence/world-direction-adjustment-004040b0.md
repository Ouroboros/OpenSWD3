# 世界移动方向修正汇编证据：0x004040B0

状态：`0x004040B0`、`0x00404510` 与本调用路径使用的 `0x0040BB50` 合同已按完整 LST
逐基本块实现；`assembly_exact`，原程序动态差分仍为 `blocked_runtime_oracle`

来源：`swd3.exe.lst` 完整汇编

地址范围：

- `0x004040B0..0x00404503`：根据地表与对象占位修改 `dx/dy`。
- `0x00404510..0x0040460B`：扫描目标边缘周围三条可通行带。
- `0x0040BB50..0x0040C012`：把角色足迹外围占位折叠为八方向位图。

## 1. 调用合同

`0x00402F80` 只在输入 `dx/dy` 至少一个非零且内部位 `0x14` 未启用时调用：

```text
sub_4040B0(player, &dx, &dy)
```

玩家记录的输入字段为：

```text
+0x04  世界 X
+0x08  世界 Y
+0x0C  当前地表格指针；现代实现为格索引
+0x6C  动作 HW 的足迹宽度
+0x70  动作 HW 的足迹高度
```

函数先无条件调用 `0x0040BB50(anchor, width, height, 0x60800000)`，再按水平、
垂直或对角输入修改两个分量。返回寄存器在调用方不读取，唯一合同是原位修改。

## 2. 八方向对象占位位图

`0x0040BB50` 使用 32 个 dword 临时槽，分别读取足迹上/下两行和左/右两列，再把
重叠窗口 OR 合并。返回低字节按顺时针排列：

| 位 | 方向 |
|---:|---|
| `0x01` | 西北 |
| `0x02` | 北 |
| `0x04` | 东北 |
| `0x08` | 东 |
| `0x10` | 东南 |
| `0x20` | 南 |
| `0x40` | 西南 |
| `0x80` | 西 |

每个方向不是单一角点，而是“足迹朝该方向移动一格时新覆盖的外围区域”。例如西北位
合并上边从 `x-1..x+width-2` 和左边从 `y-1..y+height-2`；其余七方向对称。

临时数组每个边只有八槽，因而正常 HW 最大为六。真实六包 ACT 的 `HW` 参数重处理
值域恰为 `0..6`；零值仍进入原函数 `<=2` 的固定三格读取分支，不能自行改成空足迹。
现代受检边界对 `>6` 和缺少原版外围内存的越界读返回显式状态，不猜测内存内容。

## 3. 三带可通行掩码

`0x00404510` 检查每格最高字节的 `0x60`，即完整 dword 的 `0x60000000`。它沿角色
边缘扫描一个宽或高为 `HW` 的 stripe，并在同一轴检查中心、负向一/二格和正向
一/二格。没有任何阻挡位的 stripe 才置位：

```text
负向二格  0x020
负向一格  0x040
中心      0x080
正向一格  0x100
正向二格  0x200
```

中心 stripe 被正负两组共同检查，但只产生同一个 `0x80`。多个 stripe 会因 HW 长度
相互重叠；同一障碍可能同时清除相邻两位。正向边界判断保留原式
`selected + distance + span < bound` 与逐轮递减 `selected` 的组合结果，没有改写成
常规矩形裁剪。

## 4. 方向规则表与分支顺序

`0x004040B0` 在栈上建立八张六 dword 表。首项是足迹边缘偏移，其余五项是对应的
对象占位位：

| 输入 | 表 `[offset, far-, near-, center, near+, far+]` |
|---|---|
| 左 | `[-1, 2, 1, 128, 64, 32]` |
| 右 | `[width, 2, 4, 8, 16, 32]` |
| 上 | `[-1, 128, 1, 2, 4, 8]` |
| 下 | `[height, 128, 64, 32, 16, 8]` |
| 同号且 `dx == -1` | `[-1, 1, 128, 2, 0, 0]` |
| 同号且 `dx != -1` | `[1, 16, 8, 32, 0, 0]` |
| 异号且 `dx == -1` | `[-1, 64, 128, 32, 0, 0]` |
| 异号且 `dx != -1` | `[1, 4, 8, 2, 0, 0]` |

水平和垂直输入先检查中心 stripe 与 `center` 占位；不能直行时严格依次尝试负向一格、
正向一格、负向远端、正向远端，全部失败才把两轴清零。该顺序会把单轴输入扩成对角
输入，也可能把原轴清零后改为侧向移动。

对角输入不调用 `0x00404510`，只用对象占位位图。目标角被占用后先保留水平分量，
再尝试保留垂直分量，最后停止。`dx+dy` 使用 32 位回绕结果区分同号/异号；异号表
保留垂直分量时对表首项取负。
