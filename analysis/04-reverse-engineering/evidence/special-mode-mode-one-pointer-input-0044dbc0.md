# 模式1主指针输入分派 `0x0044DBC0`

状态：`platform_adapted`

## 1. LST锁

权威范围为`swd3.exe.lst`的`0x0044DBC0..0x0044DEF0`，372行，无外部FUNCTION CHUNK。caller为`0x0044EA60`。入口先调用已关闭BA40输入状态更新；modern接收该调用后的单帧指针、低位输入和滚动区snapshot，不重读平台设备。

所有行为callee已经闭环，函数直接调用E9D0、DF00、DFF0、E0C0、E1B0、E260、E330和E4A0，不保留opaque边界。

## 2. level1

严格矩形：`x > 0x118 && x < 0x1B2`，`y > 0x144 && y < 0x15C`。列索引按`(x-0x118)/55`得到0..2，只替换packed低两位。输入bit0置位时随后确认；无论确认是否发生，输入bit2仍在原后续位置触发E9D0退出。

## 3. level2列表、按钮与确认

仅输入低两位任一置位时处理列表/确认：

- 列表外框严格为`x(0x9E,0x1F4)`、`y(0x3C,0x181)`。
- 行号为`(y-0x3C)/25`。
- 行号不等于当前cursor：先播放BF，发布该行，再调用DF00；DF00按自身语义再推进一次并播放BF。
- 行号相等时，左按钮严格为`x(0x178,0x191)`，右按钮为`x(0x193,0x1AC)`；两者y均严格为`row*25+(0x3D,0x50)`，分别调用E260/E330。
- 确认矩形严格为`x(0x1B8,0x1E0)`、`y(0x193,0x1AF)`，调用E4A0。

之后输入bit2触发E9D0并立即返回。

## 4. level2滚动区

仅滚动区启用且total按i32大于13时继续；x严格为`(0x1ED,0x1FF)`。同帧按原顺序独立检查：

1. y严格`(0x31,0x43)`调用DFF0。
2. y严格`(0x177,0x187)`调用DF00。
3. y按i32严格落入动态后退区调用E1B0。
4. y按i32严格落入动态前进区调用E0C0。

不是else-if。动态区重叠时同帧必须先后调用E1B0与E0C0。

## 5. level3、level4与level10

level3底部矩形严格为`x(0x153,0x1E2)`、`y(0x1A8,0x1C0)`；level4为`x(0xFA,0x17E)`、相同y。列号均按`(x-min)/66`，0调用E260，非0调用E330；随后低两输入位任一置位再调用E4A0。有效底部矩形不要求输入位即可先执行左右动作。矩形无效时输入bit2走共同E9D0退出。

level10只要规范化输入低四位任一非0就把level写2，不调用E4A0。

## 6. typed-stop与验证

任何callee typed-stop立即停止主分派并保留其前缀。普通完成路径保留原同帧后续检查；动作mask可记录同帧多调用。
