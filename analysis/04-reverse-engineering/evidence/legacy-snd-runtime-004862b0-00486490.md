# SND 运行时索引与 sample buffer 实现复核

最后更新：2026-08-09

状态：`assembly_exact`、`asset_verified`、`platform_adapted`

完整 LST 是唯一行为真值；IDA 伪码只用于定位。

## 1. 汇编范围

- `0x004862B0–0x00486422`：打开 `all.snd`，从 `+0x1C` 读取固定
  `0x203A0` 字节磁盘索引，并生成 `0xBB80` 字节运行时表。
- `0x00486490–0x00486574`：以一基 sound ID 查找运行时槽，读取载荷并按类型生成
  返回缓冲区。
- `0x00489EB0`：EXE 自带的重叠感知 `_memcpy`；本调用中目标低于来源，18 字节按
  正向次序复制。

`0x00486430` 的完整 buffer 回收仍归下一单元；当前 `LegacySndArchive::close()` 只覆盖
尚未建立 sample 所有权时的表清零与文件关闭。

## 2. 实现映射

- `LegacySndRuntimeEntry` 固定为四个 32 位字段、16 字节；表固定 3000 项。64 位宿主
  不把原 32 位指针字段扩成原生指针，暂以 `buffer_token` 保留槽宽，实际所有权在
  sample manager 单元接入。
- 初始化忽略头部声明项数，无条件读取并转换全部 3000 个 44 字节记录：长度只保留
  低 26 位，类型只取磁盘 `+0x20` 低两位并左移 26，引用计数和 buffer token 清零。
- `load_sample()` 保留一基编号、零文件偏移失败、类型零的 24 字节前缀、43 字节模板、
  18 字节正向重叠复制及四个字段覆写。类型一不覆写；类型二、三无前缀但仍执行同一
  模板复制和头部改写。
- 当前 `all.snd` 的 ID 506/507 不会被修成合法 `data` 标签；两个跨块长 view 也不会
  按同偏移短记录去重。

## 3. 兼容隔离

原函数把调用方目录字节和 `all.snd` 直接拼入固定 1024 字节缓冲区，并以
`OPEN_ALWAYS` 打开；随后不检查分配、定位和读取结果。重写接收已经由数据目录边界解析
出的完整路径，以只读 `open_existing` 打开，并拒绝缺失、截断、文件窗越界及会触发原版
堆越界的过短载荷。这些状态都不属于当前正确资产的有效路径，标记为
`platform_adapted`，不改变有效 sound ID 的返回字节。

原函数对 sound ID 零和大于 3000 不做检查，会访问表外内存。重写在 API 边界返回明确
错误；有效的 `1..3000` 一基公式不变。

## 4. 验证结果

合成夹具覆盖：

- 头部声明数不控制固定 3000 槽循环；
- 长度高六位和类型低两位的打包；
- 类型 0、1、2、3 的读取位置和后处理；
- 一基边界、空槽、截断索引、文件窗越界和原模板越界隔离；
- close 后表和打开状态清零。

真实 `all.snd` 回归覆盖全部 664 个非空 view：

- 662 个唯一载荷偏移；
- 运行时读取总量 `117128703` 字节；
- 返回分配总量 `117144639` 字节；
- ID 270/277 保留 `0x01DE1747` 长度和原始跨块偏移；
- ID 506/507 返回 `00 00 74 61` 块标签；
- 按 sound ID 顺序拼接全部返回缓冲区的 SHA-256 为
  `38ecbbcbb7473ab8c8ec116837b8c472fa7ed274ad42e4a0e0f04aaef6241e27`，与既有独立
  资产目录结果一致。

验证命令与结果：

- WSL Linux Clang core：67/67 CTest 通过，真实归档测试 6.36 秒。
- Windows LLVM app：69/69 CTest 通过，真实归档测试 4.69 秒。
