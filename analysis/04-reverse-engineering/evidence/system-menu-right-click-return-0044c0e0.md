# 在系统菜单右键返回时关闭页面、退回上一级或取消按键编辑 `0x0044C0E0`

状态：`platform_adapted`

## 1. LST锁

权威范围为`swd3.exe.lst`的`0x0044C0E0..0x0044C13D`，跳转表为`0x0044C140..0x0044C15E`，无外部FUNCTION CHUNK。直接caller为`0x0044B070+0xDE`，入口同时由G05游戏内系统菜单回调组保存。

`0x0044B070`在输入标志低字节的`0x0C`非零时调用本函数。输入归一化证据确认位2和位3分别是右键单击、右键双击，因此这是系统菜单的右键返回行为。

函数先读取完整输入锁；非零时原值返回，不读取页面。输入未锁定时按11项页面表执行：

- 顶层页面：共享生命周期低16位减一；直接复用`release_legacy_system_menu`释放记载清单、查询地图效果并刷新设置说明文字；随后直接复用`bind_legacy_standard_mode_callbacks`，按递减后的生命周期和原游戏内菜单主键恢复G05回调组。
- 页面1和页面2：页面值分别减为0和1，退回紧邻的上一级。
- 按键设置页：不立即离开按键编辑，而是把选择写成17，使既有确认路径执行“放弃”。
- 页面10：清为0，关闭不可用提示并回到顶层。
- 页面3、4、6、7、8、9：保持页面和值不变。

页面0保留原程序的严格顺序：生命周期递减、页面释放、回调重绑。16位递减保留自然回绕；回调主键和生命周期均由typed状态提供。关闭callee和回调绑定callee均已独立关闭，因此不再保留`exit` opaque命令。

## 2. caller回收
