# 启动对话框汇编证据：0x00424440

状态：已从完整汇编逐基本块复核；平台无关状态机和资源驱动 SDL3 界面已实现，待依赖接线与真实工具链

来源：`swd3.exe`

SHA-256：`0bac897a7557735b22607d8c8f0a79a3e7ae7729deb56593fd91c21e10baee0c`

函数范围：`0x00424440` 至 `0x004248ED`

## 1. 消息入口

函数只专门处理以下消息，其余路径返回零：

- `0x0010` `WM_CLOSE`；
- `0x0110` `WM_INITDIALOG`；
- `0x0111` `WM_COMMAND`；
- `0x0200` `WM_MOUSEMOVE`；
- `0x0201` `WM_LBUTTONDOWN`。

`WM_INITDIALOG` 与 `WM_CLOSE` 返回一；命令和鼠标专门路径执行副作用后仍返回零。

## 2. 初始化布局

对话框逻辑尺寸为 640×480。原 Win32 路径用屏幕宽高与标题栏高度计算
居中坐标，再设置背景控件 `0x405` 为 `(0,0,640,480)`。

五个悬停控件的位置固定如下：

| 控件 ID | x | y | 宽 | 高 |
|---:|---:|---:|---:|---:|
| `0x40E` | 48 | 4 | 39 | 180 |
| `0x40F` | 92 | 4 | 39 | 180 |
| `0x410` | 489 | 4 | 39 | 180 |
| `0x411` | 531 | 4 | 39 | 180 |
| `0x412` | 570 | 4 | 39 | 180 |

随后把当前五个显示字节和上一轮五个显示字节全部清零，设置对话框焦点并
返回一。当前显示值只使用零和五，直接作为旧 `ShowWindow` 的参数。

## 3. 关闭与命令

`WM_CLOSE` 无条件 `EndDialog(..., 6)`。

`WM_COMMAND` 只取 `wParam` 低 16 位，并对 `1022..1026` 使用连续跳转表：

| 命令 ID | 汇编行为 |
|---:|---|
| 1022 (`0x3FE`) | 打开模板 `0x70`、过程 `0x00425470` 的辅助对话框；忽略其返回值，然后以结果 2 结束父对话框 |
| 1023 (`0x3FF`) | 调用 `0x00424930("www.softstar.com.tw")`，不结束对话框 |
| 1024 (`0x400`) | 拼接工作目录与 `Readme.txt`，调用 `0x00424A60`，不结束对话框 |
| 1025 (`0x401`) | 以结果 6 结束对话框 |
| 1026 (`0x402`) | 以结果 3 结束对话框 |

这些仍是数字合同；本阶段不凭按钮位置替它们强加业务名称。

## 4. 鼠标热区

函数把 `lParam` 低 16 位当作无符号 x，高 16 位当作无符号 y。只有
`7 <= y <= 0xBB` 才可能命中热区：

| 索引 | x 半开区间 | 显示控件 | 附加门 | 左键动作 |
|---:|---:|---:|---|---|
| 0 | `[0x2B,0x52)` | `0x40E` | 内部位 `0x12` 非零 | 结果 1 |
| 1 | `[0x57,0x7E)` | `0x40F` | 无 | 结果 2 |
| 2 | `[0x1E4,0x20B)` | `0x410` | 无 | 打开官网 |
| 3 | `[0x20E,0x235)` | `0x411` | 无 | 打开 `Readme.txt` |
| 4 | `[0x235,0x25C)` | `0x412` | 无 | 结果 6 |

内部位 `0x12` 是启动路径刚写入的“至少存在一个存档”位；为零时第一个
热区既不显示、也不发声、更不响应点击。

每次鼠标消息都先把当前五个显示字节复制为上一轮，再把当前值清零。命中
热区后只把对应字节写五。若该热区上一轮值为零，本轮末尾播放资源
`0x77`、标志 `0x42007` 的声音；停留在同一热区不重复播放，离开所有热区
也不播放。

`WM_LBUTTONDOWN` 与 `WM_MOUSEMOVE` 执行相同的显示状态更新，区别只在命中
时是否执行上表动作。即便调用了 `EndDialog`，本次路径仍继续提交五个
显示值，并在需要时播放悬停声音。

## 5. 当前实现映射

平台无关部分位于：

- `include/openswd3/app/startup_dialog.hpp`；
- `src/app/startup_dialog.cpp`；
- `tests/unit/app/startup_dialog_test.cpp`。

UT 覆盖布局常量、初始化清零、命令低字、全部热区边界、存档门、显示状态、
进入边沿声音以及辅助对话框先执行再以结果二结束父对话框的调用顺序。

PE DIALOG 107 与 BITMAP 113..118 的映射、尺寸和哈希见
[`startup-ui-resources.md`](startup-ui-resources.md)。`SdlStartupDialog` 已用这些
原资源实现背景、五个悬停控件、鼠标状态机、关闭结果以及官网/Readme 动作，
并由 CMake 复制到可执行文件旁。鼠标事件在执行汇编恢复出的无符号 640×480
热区判断前，先通过 SDL renderer 把窗口、高 DPI、letterbox、viewport 和 scale
坐标转换回逻辑渲染坐标；转换失败按平台启动失败结束为结果六，不改写任何热区。

该函数由 B1 负责的数字结果、热区、显示边沿、平台资源界面和外部动作已经映射。
悬停声音归音频模块，存档存在门归持久化模块，辅助文本框归输入/UI 接线；这些
端口内部按冻结模块顺序延后，不再把 B1 的顶层映射错误标成 `partial`。真实
MSVC/LLVM+SDL3 构建与窗口 smoke 仍待完成，且当前不是 `original_diff_verified`。
