# 三条存档预览记录固定清理 `0x00406E00`

状态：`platform_adapted`

## 1. LST锁

权威范围为`swd3.exe.lst`的`0x00406E00..0x00406E21`，共16行，无外部`FUNCTION CHUNK`。唯一caller为环境/窗口重新建立路径`0x004251B0`。

函数无参数，固定按地址顺序把三条预览记录分别传给`0x004099C0`，随后普通返回。调用者不读取稳定业务返回值。

## 2. 行为与跨模块边界

三条记录尺寸均为`0x2A8`，地址连续。现代直接复用`0x00406D30`建立的预览记录类型与B11清理端口，不增加菜单状态、槽分组、装载或最终刷新：

1. 清理第一条。
2. 清理第二条。
3. 清理第三条。
4. 返回。

`0x004099C0`完整持久化owner尚待B11关闭。端口不可用时只在当前原调用点typed-stop；例如第二条不可用时，第一条清理已完成，第二和第三条保持入口内容。

## 3. 验证

`special_modes.legacy_initial_menu`覆盖完整三次固定顺序与第二次不可用前缀；断言第一条已清、后两条未改，不伪造后续调用。
