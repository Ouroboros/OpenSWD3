# 点击系统菜单上一页按钮时翻页或选中本页第一行 `0x0044B930`

状态：`platform_adapted`

## 1. LST锁

权威范围为`swd3.exe.lst`的`0x0044B930..0x0044B9FA`，无外部FUNCTION CHUNK。直接caller为`0x0044B070+A0`，另由游戏内菜单回调表保存入口地址。

函数首先读取完整输入锁；非零时原值返回，不播放提示音，也不修改页面。输入锁为零时按系统菜单页面执行：

- 页面0：当前页不是0时先播放提示音，随后写入第0页；已经位于第0页时不重复播放。
- 页面1：子页2直接复用系统菜单左箭头逻辑，列表翻到上一页；子页3和4把行选择写为0并播放提示音；其他子页保留`子页-4`返回值。
- 页面2：仅子页4把详情值加1。原值先写回并作为返回值；有符号结果大于等于2时再把状态夹为1，因此返回值保留夹取前结果。32位加法回绕为负数时不夹取。
- 页面5：把固定选项写为0，再播放提示音。
- 页面3、4和其他值：不修改状态。

提示音参数使用完整32位sample owner。所有页面都保留原程序最后一次写入EAX或提示音调用结果。

## 2. caller回收

`0x0044B070`在输入状态查询后重读坐标，并继续以有符号比较检查上一页按钮的动态左右边界。命中后直接调用`page_up_legacy_system_menu`，合并helper计数、返回值和最终命令；旧的未说明职责回调已删除。
