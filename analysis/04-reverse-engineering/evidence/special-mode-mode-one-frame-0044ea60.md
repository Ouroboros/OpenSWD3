# 模式1商店整帧输入、列表绘制与呈现 `0x0044EA60`

状态：`platform_adapted`

## 1. LST锁

权威范围为`swd3.exe.lst`的`0x0044EA60..0x0044F76F`，共1449行，无外部`FUNCTION CHUNK`。caller为主帧`0x0040A570`。

入口直接复用已经关闭的运行环境初始化、九动作初始化、主指针输入、备用输入、记录权重、装备贡献、属性差值和分段滚动条typed入口。主surface获取、低层面板、frame、文字、动作、矩形、软件鼠标及最终提交属于平台绘制边界，由窄请求端口表达；端口不解释商店状态。

## 2. 入口标志与输入顺序

入口固定先组成三种颜色。模式请求bit31置位时，先清bit31，再直接初始化暗灰双缓冲、工作区和九条动作；callee停止时不继续。随后重新读取模式请求，bit29置位时重新初始化九条动作，并用`& 0x0FFFFFFF`清除高四位。

每帧输入顺序固定为：

1. 主指针输入`0x0044DBC0`。
2. 备用输入`0x0044F920`。
3. 重新读取模式请求。

两种输入可在同帧先后生效。请求为0或`0xC0000001`时，在任何surface访问前返回。主指针的动态分页上下界取上一帧分段条发布值；这保留原全局值跨帧存在的行为。

## 3. 工作画面与一级页面

继续绘制时先取得主surface并发布surface准备，再在原`0x4B000`像素写点检查两端跨度；成功后把第一份活动暗灰缓冲完整复制到surface。第二份缓冲是level2退出恢复父帧时的备份，不能在此混用。

一级页面绘制固定商店问题和“买、卖、离开”三项。packed低两位为0、1、2时，选框X分别为`0x114`、`0x14B`、`0x182`。页面结束仍走公共软件鼠标和呈现尾。

## 4. 二级列表、角色动画与价格

level大于1时先绘制四名存在角色及底部基础区域。level大于等于2时绘制执行按钮、买/卖标题、列表区域和当前工作链：

- 只从当前可见head开始，Y从`0x40`每项加25，到`0x185`前停止，因此最多13项；原自环也只会重复画到该固定边界。
- 当前窗口内cursor对应项先绘制属性差值。记录ID非`0xFFDC`时再绘制图示、详情框和完整名称。
- 四名角色动作先统一写variant 13，Y各加1并在16夹住。记录raw `+0x21`低三位非零时，再按raw `+0x3B`的bit7、6、5、4分别决定是否回退2并在8夹住；首名缺位写variant 57，其余缺位写variant 5，保留原寄存器残值造成的不对称。
- 每项名称按`%-14s`、价格按`%6d`、数量与装备贡献按`%3d`绘制。价格读取raw `+0x52`的u16，按买100%或卖60%计算。
- 两个调值动作每项都重建为variant 28、29。只有选中项递减各自u16动画状态；signed下溢时夹0，否则保留phase 1位移。

列表尾重新计算总价。卖出模式先对总价取负，再从余额执行32位减法，所以显示余额实际为原余额加卖出总价。

## 5. 分页条与覆盖层

总记录数按i32大于13时处理frame flags：低nibble非零先减1并置overlay bit0，高nibble非零再减1并置overlay bit1，只写回原状态低16位。随后直接调用已关闭分段条：

- X=`0x1EE`，Y=`0x42`，高=`0x134`。
- 第一比例为窗口内cursor/total。
- 第二比例为`(window offset + cursor)/total`。
- 四个输出写回下一帧主指针动态分页区。

level3绘制买入或卖出总价确认和确定/放弃选项，bit2选择第二列。level4绘制“要马上装备吗”及确定/放弃，bit3选择第二列。level10绘制余额不足提示。三个覆盖层都在二级列表完成后追加。

## 6. 公共呈现与typed-stop

正常帧最后固定把软件鼠标frame写13，绘制软件鼠标，以selector `0x2711`提交当前surface。输入退出导致请求0或外部转换请求时，不执行该尾部。

现代停止点只位于原始读取或调用位置：运行初始化、输入callee、surface/工作缓冲跨度、低层绘制请求、装备贡献链、记录权重链和分段条frame。停止前已完成的颜色、输入、surface准备、列表文字、动画和动作状态均保留。

## 7. 验证

`special_modes.legacy_initial_menu`覆盖：

- 三颜色及主指针→备用输入→模式请求早退顺序。
- 一级页面三列选框、第一份活动暗灰帧复制、软件鼠标frame13和最终提交。
- 两项可见列表、选中图示、属性差值、四角色不对称动画、价格/数量格式、双箭头phase和总价区域。
- 14项总数触发低/高nibble衰减、overlay 3及四个分页边界输出。
- level3买卖确认、level4立即装备、level10余额不足覆盖层。
- bit31运行初始化和bit29动作重置同帧连续执行。
- surface缺失时先发布prepare，再在完整帧写点停止。
