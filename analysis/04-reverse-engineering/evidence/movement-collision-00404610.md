# 玩家足迹移动碰撞汇编证据：`0x00404610`

状态：`assembly_exact`；有效地图会话适配已实现并通过固定状态 UT；原程序动态差分待统一 oracle

唯一行为来源：`swd3.exe.lst` 的 `0x00404610..0x00404BDB`

直接调用者：`0x00402F80` 两处

直接被调者：`0x004050B0` 十二处

## 1. 调用合同

调用形式为：

```text
sub_404610(role_index, delta_x, delta_y, &hit_role_index)
```

入口先把输出角色索引写成 `0xFFFFFFFF`。角色记录地址按
`0x004BABA8 + role_index * 0xD8` 计算，并读取：

| 偏移 | 用途 |
|---:|---|
| `+0x04` | 世界 X，逻辑右移四位得到 tile X |
| `+0x08` | 世界 Y，逻辑右移四位得到 tile Y |
| `+0x0C` | 当前地图格指针 |
| `+0x6C` | 足迹宽度 `w` |
| `+0x70` | 足迹高度 `h` |

分支选择值严格按 32 位回绕计算：

```text
selector = delta_x + 3 * delta_y + 4
```

代码只检查 `selector <= 8`，不分别检查两个分量是否位于 `-1..1`；因此其他输入组合可以别名到九个分支之一。

## 2. 单格顺序和返回

每个候选格都严格执行：

1. 读取四字节格值并只保留低八位。
2. 低八位非零时立即返回该值，不再查询角色。
3. 低八位为零时调用 `0x004050B0(tile_x, tile_y)`。
4. 命中角色时写出角色索引并从共享路径返回零。

局部返回值初始为 `0xFFFFFFFF`。无扫描的中心/default 分支以及零长度单边分支会保留该值；完成至少一次全零扫描则返回零。

## 3. 九个分支

令 `p` 为 `+0x0C` 所指格的索引、`S` 为地图行宽 `0x004B7930`、`x/y` 为角色 tile 坐标。区间均按无符号 `<` 循环，所有表达式按 32 位回绕。

| selector | 常用方向 | 第一段 `(格索引；tile)` | 第二段 `(格索引；tile)` |
|---:|---|---|---|
| 0 | `-1,-1` | `i=0..w-1`: `p-S-1+i`; `(x+i-1,y-1)` | `j=0..h-1`: `p-S-1+j*w`; `(x-1,y+j-1)` |
| 1 | `0,-1` | `i=0..w-1`: `p-S+i`; `(x+i,y-1)` | 无 |
| 2 | `1,-1` | `i=0..w-1`: `p-S+1+i`; `(x+i+1,y-1)` | `j=0..h-1`: `p+w-S+j*w`; `(x+w+1,y+j-1)` |
| 3 | `-1,0` | `j=0..h-1`: `p-1+j*w`; `(x-1,y+j)` | 无 |
| 4 | `0,0` | 无 | 无 |
| 5 | `1,0` | `j=0..h-1`: `p+w+j*w`; `(x+w,y+j)` | 无 |
| 6 | `-1,1` | `i=0..w-1`: `p+S*h-1+i`; `(x+i-1,y+h)` | `j=0..h-1`: `p+S-1+j*w`; `(x-1,y+j+1)` |
| 7 | `0,1` | `i=0..w-1`: `p+S*h+i`; `(x+i,y+h)` | 无 |
| 8 | `1,1` | `i=0..w-1`: `p+S*h+1+i`; `(x+i+1,y+h)` | `j=0..h-1`: `p+w+j*w`; `(x+w,y+j+1)` |

第二段的物理格步长确实是角色宽度 `w`，不是地图行宽 `S`。证据是
`0x00404713/0x00404868/0x004048D7/0x00404949/0x00404A36/0x00404B96`
的 `lea ..., [ebp+esi*4]`，其中 `esi` 在 `0x0040465E` 来自角色 `+0x6C`。
部分对角分支还会用同一物理格地址查询不同 tile 坐标。这些均作为原版行为保留，不按通常矩形边缘算法修复。

## 4. `+0x0C` 的物理含义

`0x0040604F..0x00406067` 和 `0x0040F2C1..0x0040F2ED` 都按下式写入：

```text
map_base_0x004B7948 + ((world_y >> 4) * S + (world_x >> 4)) * 4
```

`0x004120B0` 后续也按方向表和 `S` 调整该指针。因此它是全局四字节地图格表中的当前位置，不是角色私有足迹缓冲区；上述按 `w` 步进属于原程序自身的可观察逻辑。

现代实现仍保留精确 `0xD8` 角色布局，但在独立运行时把 `+0x0C` 的 32 位值解释为受检格索引，通过小端四字节 surface grid 读取。合法状态保持汇编顺序；越界角色或格索引只在平台边界返回明确状态，避免把旧的裸指针越界带入现代进程。

- `tests/unit/world_map/legacy_movement_collision_test.cpp`

UT 覆盖九个分支的完整格地址与 tile 查询顺序、事件低字节优先、角色命中提前返回、selector 别名、default、零宽重复地址、32 位回绕，以及现代 span 边界。Linux Clang 全套为 111/111，Windows LLVM `app` 全套为 115/115。

本函数的输入输出完全可由汇编和固定状态确定，当前实现不需要启动原版。最终原程序帧状态差分仍按项目统一 Frida spawn oracle 执行。
