# 点击系统菜单上箭头时选择上一项或降低游戏设置 `0x0044BA20`

状态：`platform_adapted`

## 1. LST锁

权威范围为`swd3.exe.lst`的`0x0044BA20..0x0044BB9C`，无外部FUNCTION CHUNK。入口由游戏内菜单回调表保存。

函数首先读取完整输入锁；非零时原值返回，不修改页面或设置。输入锁为零时按系统菜单页面执行：

- 页面0：页签减1；结果为负时写回0并保留负返回值，否则播放提示音。
- 页面1、子页2：直接复用左箭头翻页逻辑。
- 页面1、子页3：按当前设置列处理音效、音乐、置换空间、地图效果、文字速度和战斗速度。
- 页面1、子页4：行选择减1；结果小于等于0时写回0，保留夹取前返回值。
- 页面2、子页4：详情值减1；结果为负时写回0，保留夹取前返回值。
- 页面5：固定选项减1；结果为负时回绕到18，再播放提示音。
- 页面3、4及其他值：不修改状态。

## 2. 六项设置

- 音效索引减1，小于等于0时夹为0，再按夹后索引试听。
- 音乐索引减1，小于等于0时夹为0，再应用夹后索引。
- 置换空间减40，小于等于60时写回60；返回值保留夹取前结果。
- 地图效果关闭服务48。
- 文字速度索引加1，大于4时夹为4，并同步发布夹后值。
- 战斗速度索引减1，负值写回0；返回值保留夹取前结果。

代码、消息结构和测试字段已同步使用六项原版Big5设置名称，不再使用`message_*`或`service`代称。
