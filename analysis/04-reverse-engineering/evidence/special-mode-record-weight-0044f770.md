# 汇总特殊模式记录链的数量权重 `0x0044F770`

状态：`platform_adapted`

## 1. LST锁

权威范围为`swd3.exe.lst`的`0x0044F770..0x0044F7C5`，48行，无callee、无外部FUNCTION CHUNK。caller为待审计的`0x0044E330`和`0x0044E4A0`。

倍率只读取打包模式最低位：

- bit0为1：倍率60。
- bit0为0：倍率100。

逐条遍历工作区记录链：零扩展读取记录`+0x52`的u16权重和`+6`的u16数量A，依次做两个32位低位乘法：`weight * quantity * percentage`。把最终32位乘积按i32解释并除100，C有符号除法向零截断；贡献再按32位回绕累加。

不能改为64位乘法、浮点百分比或每次乘法后提前除法。

## 2. typed-stop

null head返回0。链环只在即将重复读取节点时停止，返回此前完整记录的累计值与访问数。
