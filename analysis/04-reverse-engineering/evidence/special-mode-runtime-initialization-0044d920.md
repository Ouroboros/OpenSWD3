# 初始化特殊模式运行环境和暗灰双画面缓冲 `0x0044D920`

状态：`platform_adapted`

## 1. LST锁

权威范围为`swd3.exe.lst`的`0x0044D920..0x0044DA39`，111行，无外部FUNCTION CHUNK。唯一caller `0x0044EA60`尚待其自身审计。

已关闭callee直接复用：

- `0x0040DC80/0x0040DCB0`：设置/清除故事位10。
- `0x00412930`：世界主帧合成。
- `0x00420490`：RGB通道差值。
- `0x00421FB0`：除四暗灰度。
- `0x0044DAA0`：九条动作记录初始化。

主surface锁定/解锁和两个堆分配属于平台资源边界，仅由窄端口提供。

## 2. 严格顺序

1. 设置故事位10。
2. 直接调用世界主帧合成；typed-stop时位10保持已置，后续不执行。
3. 清除故事位10。
4. 锁定主surface，保存像素地址，再立即用同一结果解锁。
5. 连续请求两个`0x96000`字节缓冲；两个分配调用都发生后才首次读取/写入指针。
6. 复制`0x25800`个dword，即`0x4B000`个u16像素到第一缓冲。
7. 第一缓冲按`red=-4, green=-4, blue=-8`执行RGB差值。
8. 对同一`0x4B000`像素执行`q=(r+g+b)>>2`暗灰度。
9. 把第一缓冲完整复制到第二缓冲。
10. 清44个dword工作区并把head绑定到首项；清五个运行dword、两个运行word，写enabled=1。
11. 直接调用九条动作记录初始化。
12. 清四个后置word和最后一个运行dword。

modern缓冲保留原`0x96000`逻辑字节，同时增加一个只读guard u16供`0x00420490`最后一次dword读取；guard不属于逻辑复制范围。

## 3. typed-stop

- 世界主帧失败：保留故事位10已置。
- surface锁定失败：仍执行解锁和两次分配，到原复制源读取点停止。
- 第一分配失败：第二分配仍发生，到原第一目标写入点停止。
- 第二分配失败：第一缓冲已完成复制、RGB差值和暗灰度，到原第二目标写入点停止。
- 工作区和动作记录只在两次完整复制成功后重置。

## 4. 验证

UT使用clear-only世界帧和全白RGB555 surface，验证第一像素经`(-4,-4,-8)`及除四暗灰后为`0x4E73`，第二缓冲逐像素复制，故事位10最终清除，44-dword工作区、12个运行字段、enabled和九条动作初始化完成。另覆盖世界帧失败、surface缺失、第一缓冲失败和第二缓冲失败的副作用前缀。
