OpenSWD3軒轅劍參 雲和山的彼端 · 重制执行程序

《軒轅劍參 雲和山的彼端》（v1.02 DVD 版）的重制执行程序。它取代原版的 swd32.exe，读取你已安装的原版游戏资料，在现在的 Windows 上直接运行。

剧情、战斗、数值与各种规则都和原版一样，连原版的小 BUG 也保留；会让游戏崩溃的问题则已修正。

本项目不含任何游戏资料，需要你已有原版游戏。

神魔異事錄：仿游戏图鉴的网页，列出全部怪物的数值、各属性承受伤害、招式、可偷的物品、掉落物品和说明，也收录了游戏图鉴里没有的剧情对手，可以搜索。

安装与运行

  1. 准备好原版游戏目录，例如 E:\Game\swd3。
  2. 解压后得到 OpenSWD3 文件夹，里面有 swd3r.exe、asset 文件夹和设置文件 swd3r.toml。可以整个放在任意位置，也可以把里面的东西放进游戏目录。
  3. 如果没有放进游戏目录，用记事本打开 swd3r.toml，在 [paths] 里写上游戏目录： 
    [paths]
data_dir = 'E:\Game\swd3'
  4. 运行 swd3r.exe。

设置

下面这些是重制版新增的设置。在标题画面的「環境設定」或游戏中按 Esc →「設定」里都能调整，改了立即生效并保存。

设置默认作用
啟動畫面开关闭后启动时跳过启动画面，直接进入标题画面
平滑畫面开按显示器刷新率画出移动、淡入淡出等动态，高刷新率显示器更流畅；关闭后和原版一样每 35 毫秒画一次
垂直同步开等显示器刷新再显示，消除画面撕裂
幀率上限自動每秒最多画几帧；只在平滑畫面开启时有效
繪製倍率自動平滑畫面按几倍精度绘制，倍数越高移动越细，也越耗 CPU；只在平滑畫面开启时有效
地圖填滿开地图填满宽屏窗口，能看到更大范围；菜单、战斗等画面仍是 640×480
自動連擊关自动战斗时，戴着「連擊」饰品（武聖手鐲、姜公膽）且体力足够的角色自动使用「連擊」，体力不够时照常普通攻击
道具提示关地图上看不见、但调查后能拿到道具或银币的地方显示一个跳动的箭头，还没打开的罐子、宝箱也显示；能调查时才显示，拿走后消失

exe 旁边有两个设置文件：swd3r.toml 是你自己的设置，程序不会改动它；swd3r.default.toml 是游戏自动保存的设置。两个文件写了同一项时，以 swd3r.toml 为准。
