# BOSS 属性表

数据取自游戏目录的 `mon.dat`（1–500 号怪物，按 `Database::LoadObject` 读取）和 `battle.ffd`（各场战斗的敌人编组），数值是数据文件里的原始值。

## 收录标准

怪物数据的种类字段（`ObjectData::kind`）带 0x20 位、并且出现在至少一场战斗里的怪物，共 42 个。带 0x20 位的怪物不受剧情动作和吸收影响（`ObjectData::UnkKind20`），这里用它判断头目；没有出现在任何战斗里的（主角、同伴、剧情用的形象）不收录。

不带 0x20 位的怪物里，只出现在编号 250 以后战斗里的另列一表，见文末。

## 字段说明

| 字段 | 含义 |
|---|---|
| 种类 | 图鉴分类（`ObjectData::category`）；写编号的（如 23）不在图鉴里 |
| HP | 战斗开始时的 HP（`hitPoints`） |
| 攻击、防御、速度 | `attack`、`defense`、`agility`（速度决定行动条增长） |
| 异常几率 | 附加异常状态的几率：每次掷 1–10，不超过 `ailmentChance` 即成功 |
| 招式 | 图鉴最后三行列出的招式（`itemA`–`itemC`，重复的只列一次） |
| 掉落 | 被打倒时掉落的物品；每次掷 0–19，小于 `dropChance` 即掉落 |
| 偷窃 | 能偷到的物品；括号里是偷窃熟练度为 0 时的成功率（掷 0–9，小于 `stealDifficulty` 即成功），熟练度越高越容易 |
| 战斗 | 出现在 `battle.ffd` 里的战斗编号 |
