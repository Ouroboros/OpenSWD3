## 煉妖 {#refine}

祭壇的两个栏位各放一样材料，炼化后两样各用掉一件，得到一件结果。各物品的炼法见主页的「煉妖大全」。

- 每次炼化同时算出東方祭壇和西方祭壇两个结果，选一个祭壇拿它的结果。
- 東方祭壇要在剧情里得到封神壇后才开放，之前只能选西方祭壇。
- 能放进栏位的只有妖物和輔助、恢復、兵器、防具四类物品。

### 固定配方

先查固定配方，放哪一栏都一样：

| 第一栏 | 第二栏 | 東方祭壇 | 西方祭壇 |
|---|---|---|---|
| 象牙耳環 | 象牙耳環 | 象牙耳環 | 象牙耳環 |

- 只有这一条。
- 象牙耳環是飾品，放不进栏位，这条配方实际用不到。

### 其他组合

| 步骤 | 東方祭壇 | 西方祭壇 |
|---|---|---|
| 结果分类 | 查分类表：第一栏材料的分类为行，第二栏的为列 | 查分类表：第二栏材料的分类为行，第一栏的为列 |
| 目标等级 | 两样材料的等级相加，除以 2，舍去小数，再加 3 | 两样材料的等级相加，除以 2，舍去小数 |
| 找的方向 | 看第二栏材料的分类编号 | 看第一栏材料的分类编号 |
| 编号是偶数 | 往上找：结果分类里，取等级不低于目标的最低一个 | 往上找：结果分类里，取等级不低于目标的最低一个 |
| 编号是奇数 | 往下找：结果分类里，取等级不高于目标的最高一个 | 往下找：结果分类里，取等级不高于目标的最高一个 |
| 找不到 | 得到黏怪 | 得到黏怪 |

- 一样接近时取编号在前的（物品大全的「編號」）。
- 有些物品只会是其中一个祭壇的结果，另一个祭壇找的时候不算它。
- 妖物里有一部分永远炼不出，例如蛇、獅、虎、狼。

### 例一：往上找

| 步骤 | 计算 |
|---|---|
| 祭壇 | 東方祭壇 |
| 第一栏 | 炎靈子：天使（编号 2），44 级 |
| 第二栏 | 神龍：神獸（编号 4），56 级 |
| 结果分类 | 分类表的天使行、神獸列：天神 |
| 目标等级 | (44＋56)÷2＝50，50＋3＝53 |
| 找的方向 | 第二栏编号 4，偶数，往上找 |
| 结果 | 天神里 53 级以上最低的是太白金星（54 级） |

### 例二：往下找

| 步骤 | 计算 |
|---|---|
| 祭壇 | 東方祭壇 |
| 第一栏 | 肯塔羅斯：神獸（编号 4），38 级 |
| 第二栏 | 鬥戰聖佛：魔神（编号 1），65 级 |
| 结果分类 | 分类表的神獸行、魔神列：魔獸 |
| 目标等级 | (38＋65)÷2＝51（舍去小数），51＋3＝54 |
| 找的方向 | 第二栏编号 1，奇数，往下找 |
| 结果 | 魔獸里最高的是炎顱（36 级），比目标低很多 |

### 例三：一样接近

| 步骤 | 计算 |
|---|---|
| 祭壇 | 東方祭壇 |
| 第一栏 | 吸血殭屍：活屍（编号 3），18 级 |
| 第二栏 | 玉鐲：防具（编号 19），15 级 |
| 结果分类 | 分类表的活屍行、防具列：防具 |
| 目标等级 | (18＋15)÷2＝16（舍去小数），16＋3＝19 |
| 找的方向 | 第二栏编号 19，奇数，往下找 |
| 结果 | 防具里正好 19 级的有鐵鎖手套和菟縱鞋，取编号在前的鐵鎖手套 |

### 例四：左右对调

把例三的两样材料对调：

| 步骤 | 计算 |
|---|---|
| 祭壇 | 東方祭壇 |
| 第一栏 | 玉鐲：防具（编号 19），15 级 |
| 第二栏 | 吸血殭屍：活屍（编号 3），18 级 |
| 结果分类 | 分类表的防具行、活屍列：活屍 |
| 目标等级 | (15＋18)÷2＝16（舍去小数），16＋3＝19 |
| 找的方向 | 第二栏编号 3，奇数，往下找 |
| 结果 | 活屍里最低的是妖貓（23 级），没有 19 级以下的，得到黏怪 |

### 例五：西方祭壇

用例一的两样材料：

| 步骤 | 计算 |
|---|---|
| 祭壇 | 西方祭壇 |
| 第一栏 | 炎靈子：天使（编号 2），44 级 |
| 第二栏 | 神龍：神獸（编号 4），56 级 |
| 结果分类 | 分类表的神獸行、天使列：天神 |
| 目标等级 | (44＋56)÷2＝50 |
| 找的方向 | 第一栏编号 2，偶数，往上找 |
| 结果 | 西方祭壇的天神里 50 级以上最低的是阿普洛迪（52 级） |

### 其他

- 结果比队首角色高 10 级以上时，那个祭壇不能选，显示「等級不足 無法訂契約」。
- 炼出的妖物不计入神魔異事錄的打倒次数。
