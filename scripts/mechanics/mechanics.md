## 角色屬性 {#attributes}

各项属性在原版里的实际作用（重制版的计算与原版相同）。属性都存成 16 位整数，最大 32767；表中的「上限」是超过后会被截掉、或再高也没有用的值。

| 属性 | 作用 | 上限 |
|---|---|---|
| 生命 | 降到 0 就倒下 | 9999。每场战斗开始时，参战角色的生命和生命上限超过 9999 的部分会被永久截掉。胜利升级时在 9999 上再加成长，可以暂时超过，到下一场战斗又被截回 9999 |
| 靈力 | 施放法术和部分招式时消耗（每个招式自己规定扣灵力还是扣体力） | 9999，同生命 |
| 體力 | 使用部分招式和饰品指令（連擊、投擲、召喚等）时消耗 | 9999，同生命 |
| 力量 | 力量加上装备的攻击力，就是状态页的「攻擊」。普通攻击的伤害 = 攻擊 + 随机 1～（等級 ÷ 3 + 3）− 敌人防禦，至少 1；攻击提升、攻击下降状态各增减 30%。投擲（暗殺寶錄、御夫錄）另外按「力量 × 倍数」加伤害，倍数随熟练度从 1 到 4 | 单次伤害最多 9999，攻擊减去敌人防禦超过 9999 后再高也没用。攻擊超过约 32740（有攻击提升状态时约 25200）时计算溢出，伤害反而只剩 1 |
| 耐力 | 耐力加上装备的防御力，就是状态页的「防禦」。只减少敌人普通攻击的伤害：伤害 = 敌人攻擊 + 随机 − 防禦；防禦不低于敌人攻擊时，只受 1 加随机 1～（敌人等級 ÷ 3 + 3）的伤害。法术伤害不看防禦 | 没有截断；高过敌人的攻擊后再高也没用 |
| 智慧 | 法术等按招式数值计算的伤害，额外加随机 1～（等級 + 智慧）÷（5～9）。不增加回复量 | 没有截断；单次伤害最多 9999 |
| 敏捷 | 战斗中行动条每帧增加「敏捷 ÷ 4」（減速时减半，加速、减速状态各增减 30%），满了就轮到行动。行动条的满值 = 100 ×（20 − 戰鬥速度），戰鬥速度在「環境設定」里设定，0～11 | 达到满值的 4 倍后一帧就满，再高也没用：戰鬥速度 11 时为 3600，0 时为 8000 |
| 閃躲 | 敌人攻击时掷 0～9，小于閃躲值就闪开；閃躲在 6 以下时还要先通过一次 20% 的判定，实际机率只有「閃躲 × 2%」。有人刚闪开后的下一次一定不闪；全场连续 20 次没闪开后每次有 1/3 机会闪开，连续 24 次没闪开时下一次必闪 | 10，10 以上就是必闪（刚闪开后的那一次除外）。战斗中只取 0～255，超过 255 会绕回，例如 256 等于 0 |
| 異常 | 中异常状态的机率（十分之几）。敌人的招式带异常状态时掷 1～10，不大于異常值就中招，所以越低越好，0 完全不会中异常 | 0 最好，10 以上必中。变成负数时按很大的数比较，反而必中 |
| 默契 | 没有作用：战斗和其他计算都不读取，只在升级时显示增加了多少 | — |
| 反應 | 没有作用，同默契 | — |
| 抗力 | 每个元素（火、冰、風、土、毒、光、暗、電、物）一个值，以十分之一为单位：正数多受伤害（損），−1～−10 减少伤害（抗，−10 完全无效），低于 −10 把伤害变成回复（吸） | −128～127 |
| 等級 | 普通攻击的随机加成是 1～（等級 ÷ 3 + 3），法术的随机加成也计入等級 | 战斗胜利升级只到 60 级；试玩版（剧情旗标 0x1BB0）只到 18 级 |

## 靈契 {#absorb}

靈契就是用煉妖壺收服敌人。收服的妖物放进物品栏，可以煉化，也可以装备成護駕。

- 只有賽特有「靈契」指令。
- 剧情里中國陶器变成煉妖壺后，战斗菜单才出现「靈契」。
- 成功与否看敌人等级减去賽特等级的差。

表中的「生命」是敌人当前的生命，「上限」是它的生命上限，除法取整数。

| 敌人比賽特 | 生命够低时必成功 | 生命不够低时 |
|---|---|---|
| 高 12 级以上 | — | 必失败 |
| 高 7～11 级 | 生命 ≤ 上限 ÷ 4 | 必失败 |
| 高 1～6 级 | 生命 ≤ 上限 ÷ 3 | 掷骰：高 1 级 16%、2 级 11%、3 级 6%、4 级 1%、5～6 级 0% |
| 同级～低 4 级 | 生命 ≤ 上限 ÷ 3 | 掷骰：同级 21%，每低 1 级加 10%，低 4 级 61% |
| 低 5～9 级 | 生命 ≤ 上限 ÷ 3 | 掷骰 81% |
| 低 10 级以上 | 不看生命 | 必成功 |

### 例外

- 头目一律失败。
- 蛇、獅、虎这类不能收服的敌人一律失败。
- 蟹精魔機、羯忍幻機的分类不在收服范围内，按上表一律失败。
- 同一种妖物累计被打倒或收服 20 次以上：必成功，不看上表，头目也一样。
- 这个次数就是神魔異事錄里的打倒次数，存在游戏目录的 `Fame.dat`，所有存档共用。
- 在祭壇炼出的妖物不计入这个次数。
- 有些剧情战斗由剧情直接收服敌人，不看这些条件。
- 失败时只显示「靈契失敗」。

### 调试模式

- 战斗中按 Ctrl+F2 切到「絕對靈契」：下一次靈契必成功，不看上表，头目也一样。
- 它只管一次：收服成功后就变回普通判定，没有提示。
- 「絕對靈契」还会让賽特在得到煉妖壺前就有「靈契」指令。
- 再按一次切回「正常靈契」：这场战斗里「靈契」指令会消失，就算已经有煉妖壺也一样。

## 煉妖 {#refine}

祭壇的两个栏位各放一样材料，炼化后两样各用掉一件，得到一件结果。各物品的炼法见主页的「煉妖大全」。

- 每次炼化同时算出東方祭壇和西方祭壇两个结果，选一个祭壇拿它的结果。
- 東方祭壇要在剧情里得到封神壇后才开放，之前只能选西方祭壇。
- 能放进栏位的只有妖物和輔助、恢復、兵器、防具四类物品。

## 絕技點數 {#specials}

每个角色另有一份「絕技點數」，状态页显示为「絕技 点数/需要」。点数达到要求后，在战斗胜利结算时学会下一个絕招。

### 加点

| 时机 | 点数 |
|---|---|
| 絕招打中敌人 | 每次 +2 |
| 絕招打倒敌人 | 再 +5（「絕技一覽」里「打倒另加」为「不加」的絕招除外） |
| 战斗胜利 | 站着且由玩家操作的角色 +1 |
| 战斗胜利且敌人 3 只以上 | 再 +1 |
| 普通攻击、奇術、物品、饰品指令、靈契 | 不加 |

- 点数在打中时就加上，一场战斗里没有上限。
- 已学完全部絕招的角色，点数照样累加，但不会再学。
- 剧情直接结束、没有胜利画面的战斗，胜利不加点。

### 学会

- 只在战斗胜利结算时判定。
- 只判定站着且由玩家操作的角色。
- 点数达到要求就学会，点数归零，超出的部分不保留。
- 每个角色一场战斗最多学会一个。
- 逃跑、战败和剧情直接结束的战斗不判定，已加的点数保留。
- 要学的下一个，看角色絕招列表里排在最后的絕招（见「絕技一覽」的「下一个」和「需要的点数」）。
- 靠点数学会的絕招接在列表最后，剧情教的絕招插在最前面。
- 读档会把絕招列表的顺序倒过来（原版如此），排在最后的可能换成别的絕招，要学的下一个也跟着变。
- 原版不检查是否已经学会，这时可能再学一次已会的絕招。
- 使用絕招要等怒气槽满（受到伤害时累积）。
